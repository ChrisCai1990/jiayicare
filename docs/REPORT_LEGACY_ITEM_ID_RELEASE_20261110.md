# 旧报告项目 ID 归类修复（2026-11-10）

截图所示报告的只读核对结果：数据库中共 42 条报告项目，全部缺少持久化 `itemId`；“钾、钠、氯”各自已有“维生素及电解质类 → 电解质”归类。Mongoose 在每次读取时为旧子文档临时生成新 ID，现有 PATCH 按 ID 对照旧项目时无法找到原条目，随后清空原分类并重试自动匹配；当前目录对三个单字指标没有自动匹配结果，故提交时报 3 项未归类。没有修改客户报告。

修复：PATCH 优先按稳定 ID 对照，ID 不一致时仅对前后两侧都唯一的项目身份做保守匹配，保留其原分类。重复身份或项目名称/单位/来源等发生变化时不猜测归属，继续走待归类或人工确认。原有未归类和多分类审核门槛保持。

验证：纯函数专项测试 3 项通过，后端语法与差异检查通过。生产只读模拟同一旧报告的两次加载，42/42 条项目均能唯一对应，“钾、钠、氯”原分类保留。未代操作真实报告的审核/保存；发布状态以独立回执为准。
