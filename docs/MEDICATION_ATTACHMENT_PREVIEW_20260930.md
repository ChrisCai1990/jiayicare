# 处方附件预览修复

根因：医护列表在imageUrls返回临时预览URL，编辑保存直接持久化该显示地址，后续预览找不到原始OSS对象。旧客户端无需升级即可修复：新建/编辑保存时按同客户用药记录和附件序号还原持久地址；删除、排序、再次使用均保留。拒绝跨客户引用及循环/缺失原始地址，避免继续覆盖错误。

OSS对象key解析使用URL路径，排除签名查询及片段；不因保存签名URL导致NoSuchKey。仅后端发布，跳过通用数据迁移。截图对应3条记录从同客户已审核原处方恢复，逐一核验存储及实际预览HTTP；不变更剂量、频次或审核状态。执行结果以部署及定向修复日志为准。

验证：原始地址/过期预览保存/重复编辑保存/跨客户拒绝/循环引用拒绝/签名清除/删除排序及上限，另用隔离MongoDB真实PATCH验证连续保存不损坏附件。
