# 医护端服务群身份区分

- 医护端 @ 候选及插入文字显示姓名和岗位；客户明确标注“客户”。发送仍依据选定的账号 ID，不按姓名寻找收件人。删除带岗位的 @ 文本后不保留该提醒。
- 群列表、聊天顶部与客户搜索显示稳定的 KH-客户ID，区分不同同名客户。用户端不增加“客户”标签。
- 现有单聊图片归档接口为 staff/patients/:id/chat-images/:messageId/archive-report，仅所属健管专员或超管可操作，保存原件来源并去重，类型和日期待核对。
- 系统服务群 InAppServiceGroupMessage 当前仅文字消息，没有图片/附件字段或原始资料归档入口；企微 serviceGroups 资料归档是独立流程。不能称系统服务群已支持同样能力。
- 本轮仅修改医护端身份展示，不增加自动存档，不修改客户资料。构建与合成浏览器验收结果、发布状态以工作区 release-receipts/staff-identity-* 为准。
