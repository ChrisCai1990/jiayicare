# 佣金预估与结算规则

用户确认日期：2026-09-08。

- 直接下单且无本次推广来源，不产生转介绍佣金。实际分享或推送购买、后台明确指定的归属可计提。
- 支付成功后记录预估佣金；转介绍佣金须同时满足实际服务启动和支付满连续7天，才能进入待审核。预约、分配人员、发货不等于实际服务启动。
- Admin订单管理的“确认实际服务启动”必须填写具体事项，记录操作人、说明和服务器时间。历史已完成订单、有真实核销或履约中记录的订单可作为服务已启动证据。不从订单创建时间推断支付时间。
- 服务人员绩效在服务完成或对应次数核销时生成，不适用转介绍的7天等待期。
- 后台每小时检查一次；查看佣金列表、审核、打款前也会重新检查。审核通过后仍需人工确认打款，不自动转账。
- 取消或全额退款撤销未打款佣金；退款处理中回到预估状态，禁止审核或打款。
- 部分退款按成功退款流水计算保留金额，百分比佣金按原佣金同比调整，固定额佣金不超过保留金额。保留原始计算快照避免重复扣减；金额变化后必须重新审核。缺少成功退款流水时暂停结算。
- 已打款佣金保留付款事实，退款后标记差额/追回核对，不伪装成已追回。
- 改人员保留审计记录，并重新适用上述条件。旧记录未满足条件时回到预估，已取消记录不得被自动恢复。
