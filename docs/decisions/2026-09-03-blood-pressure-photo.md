# 血压照片辅助录入

- 仅血压计屏幕照片，先识别为临时草稿，客户核对原图、读数及北京时间后才提交。识别接口不建健康记录、不计积分、不发预警，不改变体检报告人工解析审核链路。
- 复用通义千问图像服务。每次选图前告知图片发送目的与供应商；不清楚的字段留空，不推测日期。上游失败允许回到原有手工录入。
- 草稿令牌限当前客户、原图哈希、用途和24小时有效期；提交由服务端校验确认标志、图像绑定、数值和日期。保存原始识别值与客户确认时间，原图走现有健康记录媒体存储和签名读取。
- 同一客户同一原图通过唯一部分索引拒绝重复提交，包括并发重试；如数据需要修正，在已有记录中编辑。重新编码/裁剪的图片不属于像素级去重范围。
- 脉搏保存在血压记录 extra.pulse，暂不另建独立心率记录或心率趋势，避免一次图片产生重复打卡奖励。
- App及小程序的新增记录、血压打卡均提供独立照片核对区，手工路径保留。小程序需要新版本上传、审核及发布；网页部署不等于小程序发布。
- 单实例识别并发限制8，每用户每分钟5次、同时1次；多实例部署前应迁移到共享限流存储。
- 验证使用合成图片与隔离测试，不以生产客户健康数据进行识别测试。上线后仍需用实际设备照片人工验收准确性。
