# 物资出库确认与交付信息

- 医护端各岗位可录入领用、发放或实际使用。领用和发放先形成待出库申请，提交时不扣库存。
- 申请记录录入人员、物资、数量、使用客户、线下领取人或寄送方式。寄送收件人、电话、地址从客户档案带出，可在本次申请核实修改，不改写客户档案。
- 有所属健管专员的客户由该专员处理；未指定专员的申请进入健管公共待办。超管也可处理。健管确认线下领取人，或寄送地址、快递公司及运单号后，才生成库存流水并扣减实物库存；确认接口按申请幂等。
- 待办申请可由录入人或负责的健管专员撤销。已出库流水不硬删除；详情中“撤销误录”追加冲正流水，“客户退回”追加退回流水，均要求原因并保留审计记录。已有后续使用的领用不能直接撤销。
- 客户消费金额仍由独立消费记录或商城订单核算，库存使用流水不重复计销售额。商城订单的既有寄送任务仍是订单履约流程；本物资出库确认记录只管理实物库存，不能代替订单发货状态。
- 本次不迁移历史流水，也不追溯生成历史出库申请。
