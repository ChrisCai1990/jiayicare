# 专病诊疗时间轴：同次就医资料整合（2026-10-23）

## 规则

- 时间轴一条记录对应一次经人工确认的就医事件，可以关联多份已审核医疗资料。相同日期只用于提示候选；不能仅凭日期、医院名称或相似正文自动判断是同一次就医。
- 健康顾问审核新资料时，如果同一专病、同一实际就诊日期已有来源资料，须显式选择“归入已有记录”或“不同次就医，单独建立”。后端再次校验；未经选择不能继续写入。
- 合并保留每份原始资料的独立内容、结构化病历、来源报告 ID、审核人和审核时间。时间轴展示整合信息及逐份原文入口；报告仍可按自身 ID 找回关联就医记录。
- 已归档的历史重复记录由健康顾问在时间轴确认合并。仅处理有原始医疗资料来源、实际就诊日期一致的两条记录；保存使用原数组版本比较，冲突需刷新。被并入的原条目及合并操作进入留痕。
- 健管专员工作台的报告审核与“已审核门诊病历待确认专病归属”是两步。列表分开展示，工作台链接聚焦指定资料；处理后显示实际状态，不把“查看资料”误认为待审核。

## 历史与边界

已有同日记录不自动合并。用户需要核对原始资料，逐条确认。同日不同次就医可明确保留为两条；不同日期的资料需先核对实际就诊日期再判断是否同次。原始报告不删除、不改写。
