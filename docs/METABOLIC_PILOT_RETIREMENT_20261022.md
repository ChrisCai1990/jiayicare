# 体重与代谢管理试点结束

2026-10-22 按用户要求结束独立白名单试点。该决定只涉及试点卡、试点反馈和入组流程；常规健康记录、体型照片存档、营养干预方案及已保存的历史数据继续可用。

## 生产只读核对

- 试点集合中仅有一条参与记录；金娟状态为 `withdrawn`，历史求助已回复。
- 旧配置中存在 `enabled: true` 与 `accepting: true`，但所属机构当前实际未启用该试点。发布后服务端固定停止试点反馈与新入组，旧配置无法重新打开。
- 未修改或删除任何客户记录、试点历史、求助回复或健康数据。

## 行为

- 用户端 App／小程序的“记录健康数据”页移除“我的体重与代谢管理”卡片，首页移除试点求助摘要。恢复普通记录完成提示；体型照片入口保留。
- 服务端旧客户端的试点查询不再返回 `status`，已安装版本也会隐藏试点卡。试点写接口及 Admin 启用、邀请、恢复接口返回 410；健康记录创建与修改继续返回 `feedback: null`，不再写入新的试点反馈。
- Admin 导航隐藏试点入口。历史 Admin／医护接口保留供核查和处理已有未结求助。
- 微信小程序仍需单独上传、审核和发布新版本；服务端停用并不代表微信正式包已更新。
