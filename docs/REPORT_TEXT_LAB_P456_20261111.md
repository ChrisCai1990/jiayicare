# 2021 年年度报告第 4–6 页文字层补提（2026-11-11）

## 原因与修复

旧补提流程即使 PDF 文字层完整，也先渲染上下两区并预留至少 4 次视觉模型调用；指定 2021 年报告第 5、6 页剩余额度不足，因此在提取前被拦截。第 4 页已有 20 项但仍遗漏呼气试验和甲功结果。终端查看时中文曾因输出编码显示乱码，核对 Unicode 码点后确认 PDF 文字层实际可读，不能将此误判为 PDF 缺文字层。

现对年度 PDF 中具有明确“项目名称／检查结果”表头的检验表逐行解析文字层；保留栏目、页码、顺序、结果、参考范围和单位。已人工核对条目不覆盖；新条目均为待人工核对，异常状态只在原文明确标记时赋值。心电图的明确文字结果作为检查项候选。扫描双栏页仍使用既有离线 OCR，其他不符合版式门槛的页仍回退原流程。
