# 年度方案生成门槛（2026-11-14）

- 年度方案准备清单、AI 生成、保存及年度报告问题综合生成，统一要求近 12 个月有已审核的完整体检批次；该批次可解读的检查内容须齐备，同次体检的报告须全部完成健康顾问解读确认。
- 单份病历、化验、检查和体检报告的后续行动统一进入单次随访草稿。单份报告不再产生年度方案问题待审核。历史未完成的逐份年度问题草稿在后台恢复时转为单次随访草稿，保留原审核记录；已确认记录不改写。
- 年度问题的跨报告综合入口仍在年度页面，只有体检门槛满足后才可生成。报告已有服务承接、异常复查等原有排除规则继续生效。
- 本工作树仅为本地代码修改，尚未部署；真实客户待办变化须在发布并运行恢复任务后核验。
