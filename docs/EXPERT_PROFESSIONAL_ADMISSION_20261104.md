# 非医院专业人员入库（2026-11-04）

- 管理端专家招募新增人员类型：医院医生沿用医院科室匹配；心理、营养、运动复健岗位可按所属机构／团队和专业方向入库。独立执业明确填写，不生成虚构医院或科室。
- 两类均要求资质、专业、沟通、品德核验通过，姓名和原问卷手机号唯一匹配当前机构的有效账号，确认报酬。非医院类型不可用于医生账号绕过医院匹配。
- 保存类型、机构和专业至合作条件与专家档案；资源库编辑支持专业人员机构、方向，保留已核验账号绑定。转介搜索与接收方快照显示机构／专业，预约仍使用同一账号排班。
- 不修改生产专家资料，不自动完成任何人员入库。历史医生档案默认按原规则。
- 隔离 Mongo 测试覆盖无医院专业人员入库、必填项、岗位限制、账号绑定、后续资料修改及原医院匹配流程。管理端和医护端构建通过。实际部署结果见工作区发布回执。
