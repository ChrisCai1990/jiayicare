# 代谢健康风险测评与人工承接规范 V1

目标：把 GEO 内容流量转成获得用户明确授权的有效咨询线索。测评不是诊断工具，不输出疾病结论、处方、药物调整建议或疗效预测。

## 一 用户体验

1. 用户从内容页进入“3 分钟代谢健康风险测评”。
2. 页面先说明用途、数据使用方式、不是医疗诊断，以及出现紧急症状应及时就医。
3. 用户完成 8 至 10 个最小必要问题；健康信息与营销联系授权分开勾选。
4. 系统输出“当前关注方向”和“下一步准备建议”，并按规则提示就医、专业咨询或自我记录。
5. 用户可选择留下联系方式，领取评估准备清单或预约服务匹配；未授权不得直接营销联系。
6. 后台生成线索摘要，由健康管理师在约定时间内人工首响。

## 二 最小字段

| 字段 | 类型 | 用途 | 是否必填 |
| --- | --- | --- | --- |
| 当前目标 | 多选 | 减重、改善饮食、体检指标关注、建立运动习惯、其他 | 是 |
| 年龄段 | 单选 | 仅用于分层，不收集精确生日 | 是 |
| 身高和体重 | 数值 | 计算基础体重相关提示 | 是 |
| 腰围 | 数值/跳过 | 补充腹型肥胖风险教育 | 否 |
| 最近体检情况 | 单选 | 无、正常、血糖/血脂/血压/肝脏指标需关注、不确定 | 是 |
| 既往明确诊断 | 多选/无 | 识别需要优先就医或人工评估的情形 | 是 |
| 当前用药 | 是/否/不确定 | 触发“勿自行调整用药”提示 | 是 |
| 睡眠与活动 | 简短单选 | 生活方式分层 | 是 |
| 所在城市 | 城市/跳过 | 本地服务可达性，不收集精确住址 | 否 |
| 联系方式 | 手机号/微信授权 | 仅用于用户选择的联系动作 | 否 |

不收集身份证号、精确住址、病历全文、检查影像或与首轮服务匹配无关的敏感信息。上传体检报告属于另一条明确授权流程，不能与本测评默认合并。

## 三 分流规则

| 情况 | 自动结果 | 后台标签 | 人工动作 |
| --- | --- | --- | --- |
| 用户仅希望改善生活方式且无风险信号 | 提供一周记录准备清单和测评结果说明 | `基础管理` | 用户授权后 24 小时内发送服务匹配建议 |
| 体检指标关注但未报告明确诊断或急性不适 | 提醒携带最近体检结果，建议专业人员结合实际解读 | `指标关注` | 优先安排健康管理师，必要时提示线下就医 |
| 已明确慢病、长期用药、孕产、未成年人或老年高风险情况 | 明确本测评不能替代诊疗，不建议自行改变饮食/运动/用药 | `需专业确认` | 先由具备资质人员确认承接范围；不能承接则提供就医建议 |
| 用户描述急性/严重症状或明显异常 | 不展示营销转化，提示尽快线下就医或紧急求助 | `紧急就医` | 不纳入营销跟进，只保留必要安全记录 |
| 用户未授权联系 | 可查看结果与准备清单 | `未授权联系` | 不主动外呼、加微信或发送营销内容 |

## 四 给用户的结果文案边界

允许：说明用户选择的目标、值得关注的生活方式因素、准备体检资料/记录习惯的建议、何时需要就医、可选择的服务匹配。

禁止：宣称患有某疾病、预测疾病、推荐或调整药物、承诺减重数值、宣称治疗或治愈、将测评结果作为医疗诊断依据。

## 五 健康管理师首响 SOP

1. 查看系统摘要和用户授权范围，不要求用户重复填写已知资料。
2. 首句确认用户最关心的问题与方便沟通的方式；不在首次触达中做诊断或效果承诺。
3. 对 `紧急就医` 或 `需专业确认` 标签，先重申就医/专业确认边界，再决定是否提供非医疗的流程说明。
4. 对可承接线索，说明首次评估会了解的内容、准备材料、服务边界、费用口径和取消规则。
5. 每次结果记录为：已联系、预约、待补资料、不适配/已转就医、暂不考虑；“未转化原因”必须可选择。

## 六 数据和归因字段

- `first_source`：首次来源，例如 AI 搜索、抖音、小红书、公众号、转介绍、线下活动。
- `landing_topic`：进入的专题/问题编号，例如 `metabolic-q47`。
- `latest_effective_touch`：最后一次促成用户行动的触点。
- `conversion_confirmation_source`：咨询中由用户确认的来源。
- `consent_contact`、`consent_health_data`、`consent_version`、`consent_at`：分开留存的授权记录。
- `risk_route`、`lead_status`、`owner`、`first_response_at`、`outcome_reason`：用于运营和服务质量复盘。

## 七 首期验收

- 在没有授权联系时，后台不得把用户加入营销跟进列表。
- 高风险和紧急情形不得出现购买导向文案。
- 人工首响、预约、成交和未转化原因均可追踪。
- 抽检 20 条测评结果，结论、边界、授权记录和分流均正确。
