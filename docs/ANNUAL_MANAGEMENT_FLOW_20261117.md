# 年度管理流程逐项修订（2026-11-17）

## 目标流程

资料归档与审核 → 规则提示重点及 AI 起草 → 健康顾问确认管理问题、目标、行动、负责人和时间 → 年度方案按医疗／管理／其他展示 → 复用现有岗位服务流程 → 执行资料回到原问题 → 顾问按现有权限终审、确认随访 → 阶段评估按目标复盘。

AI 输入包括已审核报告解析、专项筛查、健康档案、健康数据、专病档案、阶段评估、就医协助和转介记录。AI 输出均为草稿，须保留来源、时间和待核实点；规则命中的重点须由顾问逐项处置，不自动当成确诊或已确定的服务。

## 三类方案及岗位

| 类别 | 行动 | 入口与主责 | 结果回流 |
| --- | --- | --- | --- |
| 医疗 | 当前就医、进一步检查、完善检查、定期复查 | 顾问确定问题与目标；就医协助交健康规划师全程督办，具体代办代诊陪诊由就医专员执行；会诊走现有专科转介 | 病历、检查及专家意见归档，顾问决定管理事项是否继续或调整 |
| 管理 | 营养评估及干预、运动复健评估；儿童生长发育按需提出中医评估 | 营养师和运动复健师先接评估任务，专业方案由本人负责；其他中医需求沿就医流程 | 评估基线、专业方案及阶段结果关联原管理问题 |
| 其他 | 疫苗接种、健康认知与共识 | 事项指定唯一主责；共识沟通默认健康顾问本人 | 记录客户顾虑、待澄清点、方式、频率及实际沟通结论 |

心理咨询保留现有独立通道，不在本次年度方案中自动派发。涉及额外付费的专业服务，先记录客户选择、权益和支付意愿；评估任务不等于购买连续服务。健康顾问现有监管、终审和随访确认权限保持不变。

## 各岗位工作与上下游

| 岗位 | 接收什么 | 本岗位负责 | 交给谁、留下什么 |
| --- | --- | --- | --- |
| AI | 已审核报告、专项筛查、健康档案与数据、专病档案及已归档服务记录 | 解析、归类、提示遗漏重点；起草管理问题、方案与阶段复盘；标明来源和不确定性 | 交健康顾问或对应专业人员审核，不自行确诊、发布方案或改变目标状态 |
| 健康顾问 | 报告解读、AI 草稿、当前主诉、各专业意见 | 确认管理问题、目标、基线、行动和时间；决定单学科/多学科医疗讨论；发布年度方案；确认随访与所有资料终审；负责健康认知与共识 | 向规划师、健管专员及营养/运动专业岗位分发；接收执行结果并决定继续、调整或关闭问题 |
| 健康规划师 | 顾问确定的就医协助需求与服务方式 | 督办预约、代办代诊陪诊等既有就医协助全流程，安排资源与执行人 | 把具体执行交就医专员或预约环节，回收病历、检查及服务结果给顾问 |
| 就医专员 | 规划师分配的单次就医任务 | 按既有服务路径完成资料入档和现场执行记录 | 交健康规划师核验，必要资料进入顾问终审 |
| 健管专员 | 顾问的日常跟进计划及规划师的预约安排 | 联系客户、安排预约、记录本轮结果；有续跟需要时建立下一轮当前计划 | 把结果和未完成原因回传顾问或对应督办岗位；旧轮办结不继续计逾期 |
| 营养师 | 顾问带问题和目标发起的营养评估 | 按现有评估表建立基线、出营养方案并督办干预；体成分测量按完成日滚动邀约 | 把测量与专业评估回流原问题，阶段意见交顾问审核 |
| 运动复健师 | 已关联年度问题的运动服务预约及筛查结果 | 完成首次评估、复评、训练记录与专业方案；连续服务依客户购买情况开展 | 把能力测试、反馈、方案及记录回流原问题，阶段意见交顾问审核 |
| 专科医生 | 顾问发起的单学科或多学科转介/会诊 | 提供专科判断与医疗决策意见 | 会诊记录归档给顾问；普通专家门诊由就医协助链承接 |
| 中医师 | 儿童生长发育等明确需要中医评估的问题 | 依现有就医或专业服务路径评估与提出专业方案 | 专业记录回顾问；其他中医就医需求沿就医协助链 |
| 心理咨询师 | 独立心理咨询通道中的已确认服务关系 | 按现有心理流程评估、咨询和连续记录 | 仅按原权限与顾问协作，不从年度方案自动派单 |

每条管理问题有稳定 ID。岗位任务、客户是否接受服务、实际医疗或健康结果分别记录；阶段复盘按同一 ID 读取目标和证据。

## 一个持续事项与一条当前任务

一项持续管理事项保存稳定身份、来源问题、目标、主责人、状态和历史轮次。每一轮执行任务独立留存完成凭据；同一事项同一时点最多一条当前待办。本轮完成后由负责岗位依据实际结果和完成日期确定下一轮。无法确定日期时进入待安排，不推断期限。一次性就医与会诊按既有流程关闭；需要后续管理时，另关联持续事项。

营养师出方案后应有体成分测量邀约主线：首次测量默认方案生效后第 28 天，提前 3 天进入营养师邀约待办，营养师可调整；完成测量并记录实际日期及结果后，由营养师定下一轮。不再叠加含义不明的通用营养师提醒。定期复查每轮包含检查结果、专家门诊评估和下一轮决定；不预生成全年的复查待办。

每轮工作人员任务的办结与客户是否实际检查、就医、测量分开记录。若客户本轮未做，责任岗位记录原因和下一轮约定并办结旧任务；旧轮次保留结果，不再计为工作人员逾期。逾期只依据**当前有效任务**的计划处理日期和开放状态判断，未到期的新计划不算逾期；客户医疗目标是否达到由实际资料另行核对。

## 分批实施与验收

1. **顾问纳入管理字段**：问题、证据、目标、行动、单次／滚动／待确认、首次时间；复查时间只由结构化复查计划推导。AI 已有年度研判目标草稿入口，后续统一到这些字段。旧决定保留，编辑时补齐新字段。
2. **年度方案对齐**：专项筛查及 AI 检查完善来源均进入同一管理问题清单，按来源 ID 校验对应行动；客户界面按医疗／管理／其他阅读，员工界面按主责人和状态阅读。已发布方案可按问题查看相关岗位任务、进展和执行记录；任务完成不自动等于管理目标达成。
3. **岗位衔接**：医疗服务和转介复用现有流程；营养评估携带问题和资料；运动复健已有初评、复评及服务记录表，需将年度问题与现有评估入口关联；健康认知与共识形成顾问自己的计划。结果和档案引用回原问题，专业服务不由顾问代写。
4. **滚动任务**：体成分测量、定期复查、健管日常跟进等有持续事项及唯一当前待办；每轮完成后按实际结果确定下一轮，旧任务不重新打开或改写。
5. **阶段评估**：按问题 ID 对照基线、目标、执行与结果；无执行证据写待核实，不把记录缺口当成未完成。

每批先使用合成记录验证权限、来源、重复任务、状态回流和旧记录兼容。代码变更不代表生产已发布；旧方案和历史任务不批量迁移或重排。

## 本工作树当前进度

- 第一批：专项筛查纳入支持 AI 起草空白目标和行动，顾问确认执行方式；确认值带入年度目标。来源仍以已审核专项筛查为限，AI 不保存或发布决定。
- 第二批：年度方案下的随访、服务请求和营养评估任务携带管理问题 ID；顾问可只读查看每个问题的岗位任务、负责人、进展与完成记录。旧服务请求可从来源快照回查；无可靠来源的历史任务不猜测归属。
- 第三批：新版营养方案经客户确认后生成第 28 天测量、第 25 天邀约的营养师任务。专用入口可改期，可选择“已测量”引用入档结果，或“本次未测量”记录原因并约定下一轮；两种结果均办结旧轮次，幂等生成下一轮。营养师新建方案时会冻结已发布年度方案中勾选其参与的管理问题；后续测量任务携带原年度方案和问题 ID，顾问可在问题进展中看到。当前仅适用新方案，旧营养随访不迁移。
- 第四批进行中：年度方案可新增健康认知与共识事项，顾问填写客户当前理解、顾虑、待澄清问题和沟通方式、频率、首次日期；内部随访保留一条当前任务和沟通历史。阶段复盘区分已办结旧轮次与当前有效待办，工作人员逾期只按当前任务日期判断。
- 检查及就医提醒新增“本轮已跟进但客户未做，转下一轮”：负责人记录实际情况及新的跟进日期，旧任务记工作人员本轮办结，后续任务保留原年度问题关联。新任务在自己计划日期以前不算逾期，且旧任务办结不代表客户完成医疗目标。
- 同一条医疗随访继续跟进时，工作人员保存过程记录及下次联系时间后，当前任务的工作台日期推进到该时间；原过程记录保留，旧日期不继续造成逾期。年度方案重同步不会把已推进的进行中任务改回原日期。
- 第五批：年度目标可标记运动复健评估建议；仅在客户已有可用的已支付运动服务订单后，健康顾问把订单关联到对应管理问题。现有规划师接单、健管预约、复健师评估与方案继续沿原流程；新任务、评估记录及方案携带年度问题 ID。建议本身不产生收费服务，也不代替客户选择。
- 第六批：新持续管理复盘入口在建立月度、季度、年度记录时冻结当时已确认年度方案的目标清单，汇集本期关联随访与运动复健记录。顾问归档前逐项目标选择达到、部分达到、未达到、待核实或本期不适用，并写明依据；任务办结不自动判为目标达成。评估期后才完成的任务在本期快照中仍按期末待处理展示。该入口目前仅对 `MANAGEMENT_REVIEW_MODE=allowlist` 客户启用，未迁移旧评估。
- 年度目标增加数据、症状、生活方式维度和当前基线，顾问可按资料核对修订；复盘保留该目标快照，缺少基线时明确待核对，不补造指标。上述维度并不替代医疗、管理、其他三类行动安排。
- AI 在岗位意见提交后可为每项目标生成本期证据、缺口和下一步的待核对短草稿；不会据此写入达标状态。顾问须核对并填写最终结论。
- 数据目标可显式绑定日常健康数据（体重、血糖、心率、收缩压、舒张压）或已审核报告的同名检查项，并设置可选目标方向和数值。复盘按本期原始记录列出首末值、变化和与顾问设定目标的数值差，保留来源 ID；名称、单位或数值不明确时不比较。指标专门按目标读取，避免被普通资料列表条数上限截断；若专用读取达到上限则标为可能不完整。数值差不自动判为医学达标。
- 年度方案提示已转健康顾问但尚未处理的不适主诉，链接回既有主诉处理流程；提示不自动纳入年度计划。同步管理问题或重新生成年度方案时，同一问题 ID 下的顾问目标、基线、指标绑定、营养及运动选择保留。
- 报告解读的待确认资料增加当前列表全选与清空，顾问仍须核对原件并显式确认。
- 待做：其他已审核资料来源扩展、指标原始数值与目标的结构化比较，以及从已有复健记录回查晚于服务记录才发生的年度关联。所有批次均未部署。
