# 分类独立服务群（2026-11-14）

用户确认同一客户各服务类型分别建独立群，其他建群、监管、未读、小嘉身份规则延续。服务期限说明仅为业务背景；本次不新增期限字段、自动到期、AI建群或解散。

- advisor：客户姓名+嘉医服务群，健康顾问与健管专员。
- nutrition：客户姓名+营养干预服务群，营养师与健管专员。
- medical：客户姓名+就医服务群，就医专员与健管专员。
- specialty：客户姓名+专病管理群，专科医师与健管专员。
- 仅客户当前健管专员/超管可确认建群。新群必须包含对应已分配且在职的专业人员及健管专员；同人兼岗按人员去重。不会因仅分配岗位就自动建群。
- 医护端按专业类别页签筛选；客户端每个群独立显示名称、未读数、消息预览，通知携带groupId准确进入。AI历史与人工接待仍按groupId隔离。
- 每客户每类型最多一个active群。迁移先备份群ID/成员/原索引，将仅有准确对应两岗位的旧群归类；混合或不明确群归legacy原服务群。保留原ID及全部消息，不复制聊天记录。建立按机构/客户/类型的active唯一索引后移除旧机构/客户唯一索引。
- 专项17测与隔离Mongo集成通过：迁移保留历史、同客户四群并存、旧页面无类型拒绝、重复配置版本拒绝、跨群发送及跨机构读取拒绝、未读隔离。
