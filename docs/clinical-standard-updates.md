# 临床标准更新流程

平台 Admin 的「临床标准管理」保存标准目录、原始来源、现行版本、监测状态和审核记录，并指定一名在职健康顾问。目录定义在 `shared/clinicalStandards.cjs`；新增任何指南、量表或内部判分规则时，同步登记实现路径、来源及监测方式。

系统每周检查已登记的可信来源页面或 PDF。首次抓取建立基线并发出首次核对任务；来源正文变化发出变化任务。固定文献页不一定随新版指南更新，因此所有外部标准还需每年人工复核。无法可靠抓取的量表和内部规则每年生成复核任务。抓取失败在 Admin 展示错误，不视作新版标准。

待审任务自动显示在指定健康顾问工作台；审核人需打开原始来源、写明版本与变化影响，可标记「需评估实施」或「无需更新」。审核记录不可直接修改线上算法。需要调整时，由开发修改规则、版本号及测试，部署后才生效；历史人工确认仍按原有版本检查失效。

`source` 监测是变化提示，不代表自动识别新版的医学内容。新版本若发布在不同网址，年度人工复核负责发现并更新目录。内部健康评分和癌筛口径属于平台规则，不能标注为权威指南。
