# 五岗协作与营养干预任务设计

本文确定健康顾问、营养师、健管专员、健康规划师和就医专员的执行、督导与复盘分工，并定义营养干预任务如何从已确认方案生成。业务验收以生产环境的真实操作记录为准；不为验收制造客户任务或健康结论。

## 责任归属

| 事项 | 执行及专业责任 | 日常督导 | 健康顾问参与 |
| --- | --- | --- | --- |
| 年度营养方案与调整 | 营养师 | 营养师对本专业实施负责；健管专员跟进客户执行反馈 | 查看方案与结果；不事前审核方案，不催办日常动作 |
| 日常及动态随访 | 当前执行人，通常为健管专员 | 健管专员 | 查看进度；在阶段节点复盘效果、分析整体目标偏差 |
| 预约及就医协助 | 健康规划师安排资源，就医专员执行现场任务 | 健康规划师 | 查看进度；处理需要综合健康判断的结果 |
| 就医后资料及报告 | 健管专员回收、核对和审核 | 健管专员 | 基于已核实资料决定后续健康管理安排 |

顾问的全程进度视图是只读的管理视图，不生成普通服务催办待办。异常需要顾问判断时，由责任岗位提交明确问题、依据和处理期限；顾问仅处理该判断任务。普通逾期仍由所属督导岗位处理。

## 营养干预的生成与执行

1. 营养师在现有 `PlanTemplate(type=nutrition)` 中选择有效模板，结合客户管理目标和已核实的生活方式资料制定营养方案。模板中的膳食原则、禁忌、餐次及安全约束保持为来源依据。
2. 营养师确认方案后，系统读取已确认版本、模板快照、目标和生活方式证据，生成一份**待营养师审核的任务草稿**。生成失败保留可重试状态，不发布空任务。
3. AI 只把目标拆成具体、可观察的行动，不自行诊断、修改医嘱、补造客户行为或改变模板禁忌。草稿保存方案与模板来源快照。营养师可修改或删除行动；生成失败时可重试。
4. 营养师确认草稿后，系统分别发布：客户可执行的行动或提醒；健管专员的阶段跟进事项；营养师的专业复评节点。日常饮食、饮水等重复行动以客户提醒或记录周期承接，不按天产生员工待办。
5. 阶段节点汇总目标指标、客户记录、健管跟进、营养师专业评估及资料缺口。健康顾问收到**阶段复盘**，记录目标达成情况、可能原因、需要核实的因素和整体管理决定。顾问复盘不等于审核年度营养方案；专业营养调整仍由营养师确认。
6. 新版方案或显式调整只影响尚未执行的后续任务。已完成行动及原始来源保留；不静默覆盖、不重复派发。

### 一条 AI 草稿至少包含

| 字段 | 要求 |
| --- | --- |
| 目标 | 对应方案中的明确管理目标，含观察指标、基线和目标值或可判断的完成标准；缺失时提示营养师补充，不猜测 |
| 生活方式依据 | 已核实的饮食、作息、活动、饮水等记录及日期；区分客户自述与专业核实 |
| 模板依据 | 模板 ID、版本/快照及所用字段；与禁忌或安全约束冲突的草稿不得发布 |
| 客户行动 | 具体做法、频率或记录周期、开始与结束条件；避免以餐次方案直接生成三条“完成”任务 |
| 员工跟进 | 执行岗位、触发日、需采集的证据和完成标准；仅有真实沟通或判断增量时生成 |
| 复盘安排 | 阶段日期、评估指标、未达目标的原因分类及下一步选择 |
| 状态与来源 | 待生成、待营养师确认、已发布、执行中、待复盘、结束或异常；关联客户、方案版本、模板和生成批次 |

## 阶段复盘与原因分析

营养师先确认本专业事实：执行程度、指标变化、客户反馈、方案可执行性、资料可信度及是否需要专业调整。健管专员补充客户联系和执行障碍。顾问随后从整体健康管理角度选择：继续原目标、请营养师调整、补充资料、启动其他专业协作、调整整体目标或明确结束。未达目标原因可多选：未执行或执行不足、方案不适配、目标或期限不合理、资料缺失、出现新健康情况、其他；系统只提示待核实，不自动作因果结论。

阶段复盘时间应由方案或模板显式给出；没有时间时由营养师确认，不由系统默认为固定天数。复盘结果须包含责任人和下一次复盘日，或者明确结案理由。

## 就医与随访交接门槛

每个交接节点保存原任务、交出人与接收人、时间、实际结果、附件或资料清单、未解决问题及下一动作。接收人发现资料不足可退回，并写明缺项。执行人提交完成只代表本环节完成，不能自动代替后续岗位验收。

- 就医专员提交现场结果后，健康规划师核对预约与服务执行；报告/病历资料转健管专员回收。
- 健管专员完成资料核对与逐份审核后，才把需要健康判断的内容交顾问。
- 随访由健管专员督导；需要就医资源或现场服务时转规划师督导。两类事项各有唯一当前督导人。
- 顾问只读查看上述进程；仅在阶段复盘或明确升级的综合判断节点产生本人待办。

## 与现有系统的差异及实施顺序

1. 取消年度营养方案及营养执行结果的常规顾问审核待办；保留营养师专业确认。生活方式问卷核实由营养师直接完成。
2. 顾问服务督办区改为只读进度与风险视图；普通随访提醒和就医协助提醒分别转给健管专员、健康规划师。不得将旧待办静默改派；先核对真实未结事项。
3. 扩展现有营养模板或方案数据，记录目标、指标、生活方式来源和阶段复盘时间；旧模板可继续显示，但缺关键输入时不允许自动发布 AI 任务。
4. 实现带版本和来源快照的 AI 草稿、营养师确认、客户与员工任务发布、防重复及失败重试。生产环境先在一条真实且已授权的营养服务中按正常业务操作验证，逐项核对客户可见内容、员工待办和审计记录。
5. 建立营养师专业阶段评估与顾问整体复盘的独立记录；完善就医、随访交接清单和逾期归属。扩大使用前复核真实记录中的重复、漏派和提前结案。

## 生产核对清单

只读盘点当前有效营养方案、模板字段、待审营养任务、顾问督办事项、随访及就医协助的负责人和状态，确认旧任务中哪些仍需人工收口。随后由岗位人员按真实服务操作一例，核对每次提交后的下一负责人、工作台入口、客户可见内容、阶段结果和结案凭据。生产验证不以隔离环境测试代替；发布前仍需完成代码回归与构建。
