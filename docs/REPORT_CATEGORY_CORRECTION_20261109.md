# 已审核资料大类更正（2026-11-09）

## 适用场景

已审核原始资料的 `documentCategory` 选错，例如 MRI 原件误列为门诊病历，应更正为检查报告。此处更正的是整份资料的大类，不是 `type` 或单项专项筛查分类。

## 操作与保护

- 健管专员或超管打开报告详情，选择“更正资料分类”，填写至少 5 字依据并确认。
- 保留原审核人与时间、原顾问草稿、原病历结构化结果和更正依据到 `categoryCorrectionHistory`，并记录 `dataEditLog`。
- 旧顾问草稿标记为 `superseded`；旧检查项目保存在更正历史，报告回到待解析、待审核，按新大类重新核对。离开门诊病历大类时清除专病归属。
- 与顾问退回一致，待重审期间撤出旧审核派生的专项筛查、身体成分和风险记录；重新审核后按新结果写回。
- 已入诊疗时间轴、重复上传、仅留存或处理中的报告拒绝此操作；已有入档记录须先走健康顾问撤销流程。
- 前端详情分别显示“资料分类”和“筛查类型”，避免将两者混同。
