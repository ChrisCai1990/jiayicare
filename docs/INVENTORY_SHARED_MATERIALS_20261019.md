# 共享实物库存（2026-10-19）

用户确认：实物在实际发放/领用时扣减，商城订单仅关联消费来源。

InventoryMaterial 独立保存名称、库存、成本及关联服务列表；同一物资可关联多个 Product，一项服务也可关联多种物资。服务价格仍由 Product 维护。

首次访问物资接口时将旧 enabled 商品以相同 ID 一次性复制为独立物资，数量不重算、不相加，关联原服务。使用 setOnInsert，不覆盖之后的实盘、名称或关联关系；旧 Product 与 InventoryEntry 保留。新流水同时保存 materialId、serviceProductId 和 sourceOrderId，历史 productId 作为台账键兼容。

新订单购买关联服务时不预占实物库存。发放/实际使用和领用扣减；从已领用物资使用不再扣；手工消费只记录服务收入。新流水用 requestId 防重复，服务关联按机构校验。旧订单释放的历史商城预占只影响旧 Product 数值，不自动增加实物；实物余额以盘点为准。

后台在“物资设置与服务关联”中修改实物名称及多选服务；历史仅保留原服务关联，新增关联需管理员选择具体服务，避免猜测规格或套餐。每种实物一行，展开后显示批次和有效期；未填写效期不从批次推断。效期当前是入库记录信息，未声称按批次计算剩余库存或自动过期拦截。

验证：库存创建/共享扣减/订单来源/已领用免重复扣减/服务收入/重复请求/旧台账复制专项；Admin、Staff 生产构建。发布状态以部署回执为准。
