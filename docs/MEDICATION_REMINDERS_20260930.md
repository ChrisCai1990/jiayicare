# 最终补充：当天滚动、跨日自动结束

客户明确只生成当天，早中晚同时间药物合并，次日再生成下一天。后台保留一份持续配置，不展示额外重复卡片；每天最多三个对应时间待办（配置更多时间则按实际时段）。30秒扫描跨日接续，停用、改时、删除刷新当日未来提醒。

普通未确认提醒跨日置cancelled并写入“当天提醒已自动结束，执行情况未确认”、formData.autoEndedAt及executionStatus=unconfirmed；不写completedAt、不伪造服药或人工执行，退出逾期队列。已确认完成不改；人工求助/专项持续跟进不自动关闭。旧页面不能把已自动结束提醒重新改为已完成。
