# 物资、设备与客户消费记录（2026-10-19）

## 入口

- Admin「运营管理 → 物资与设备」：从已有商城商品启用物资台账，维护成本参考、最低库存和位置；登记入库、盘点、报损；查看流水与消费来源。商品售价仍在「商城产品」维护。
- 医护端「物资与设备」：领用、实际使用、退回以及人工录入客户消费。客户详情「消费记录 → 实物消费与使用」可带入客户。

## 口径

- 启用台账时，商城商品当前 `stock` 成为期初库存；启用后 Admin 商品编辑接口不能直接改库存，须从台账办理。`stockLimited` 随启用设为 true，0 表示售罄。启用前必须先核对实物和商城库存。
- 商城仍在下单时按现有 `orderInventory` 预占商品库存，取消/退款依原流程释放；已支付商品订单自动出现在客户消费和 Admin 消费来源清单。商城订单不再人工录入第二笔销售。
- 医护人工消费单独记录本次售价、数量、客户和凭据。医护只能用后台当前售价；管理员可更正售价。人工消费是业务记录，不能替代支付单或收款核实。
- 领用减少库房可用库存；从已领用物资或客户已付款商城订单登记实际使用时不再扣一次。商城订单仅允许关联一次实际使用。客户实际使用只追踪去向，不增加收入。退回须关联原领用人员。可重复使用设备的使用不消耗领用余额，归还后重新成为可用库存。
- 每条库存流水保存当时数量、成本参考、成交价、经办人、客户/领用人、批次/设备序列号和时间。盘点差异单独留痕。可重复使用设备逐台登记序列号。

## 当前边界与上线核实

- 商品现有库存是可用总量；批次和序列号在流水中可追溯，但商城自动预占尚未分配到具体批次/设备。发货时仍需人工核对实物批次和订单。
- 页面只展示最近 100 条库存流水和最近 500 条人工/商城消费，概览金额也按该 500 条计算；不能当作全量财务报表。
- 上线前逐项核实代餐、血糖监测耗材、心电设备及耗材是否已分别建为商城商品，确认单位、当前实盘量、售价、成本、最低库存、存放地点。不要将“主机借用”和“一次性耗材消耗”合成一个商品。
- 本次不改已有订单、支付、退款历史，也不自动补造过去的批次或人员使用记录。
