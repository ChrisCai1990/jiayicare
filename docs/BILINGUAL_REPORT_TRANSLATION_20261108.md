# 报告英文参考翻译修订（2026-11-08）

- 小程序和 App 的体检报告列表接入中英文固定文案；常见报告标题可直接显示英文，原题同时保留。未知标题仍显示原文。
- 英文模式下展开本人已审核报告，可点“Translate this report”生成英文参考译文。翻译前单独取得“报告英文参考翻译”授权；不借用宽泛的健康资料 AI 授权。
- 后端只发送标题、检查项目名称、部位、检查所见和诊断意见等已提取文字给通义千问。报告图片不发送；结构化数值、单位和参考范围不单独发送，叙述文字可能含测量值或姓名。
- 原始报告及结构化原文字段不被翻译覆盖。译文作为独立缓存，以原文哈希核对有效性；报告修改后旧译文不再展示。报告被退回核对或尚未审核时不生成译文。
- 英文译文标注为机器翻译参考，并保留查看原件入口。家庭成员档案可以查看已有译文，但不能代本人发起 AI 翻译授权。
- 验证：后端翻译专项 3 项通过；小程序 Taro 微信构建与构建产物运行检查通过；App Expo Web 导出及发布前配置检查通过。
- 当前为本地代码修订，未部署后端、未上传新版小程序，也未发布 App。真实模型译文和真机界面尚未验收。
