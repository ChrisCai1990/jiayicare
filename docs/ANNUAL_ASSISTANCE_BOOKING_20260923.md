# 年度协助预约与进度隔离

## 已实现（未部署）

- 年度服务需求按原方案、原日期、原事项关联，不再拿整份年度方案的随访充当本服务进度。仅提醒不纳入本项服务进度；缺失来源时不扩大匹配。
- 健管服务面板纳入年度就医/检查协助的预约阶段，支持既有未来日期筛选，不纳入普通提醒。复用来源随访ID，预约回执独立存储，不重复创建随访。
- 健管专员登记实际预约日期、医院、科室、备注。仅所属健管/超管可确认；并发/重复提交拒绝，记录操作人和时间，不覆盖顾问计划，不完成原随访。非白名单不开放接口。
- 规划师看到本项预约阶段；关联下拉限定原事项，未预约不得新增服务关联。既有服务关联不自动撤销。

## 明确未完成

原“关联已存在服务”尚未替换为带入计划/预约信息的直接派单页面。服务合并、预约更改历史以及正式派单联动需要后续衔接，不应称完整协助闭环已交付。本批不修改生产客户数据，不自动创建订单、扣费、发送通知或执行历史回填。

## 验证

全量1255项：1253通过、0失败、2独立数据库用例跳过。员工端1914模块构建通过。包含预约HTTP本人/越权/纯提醒/重复/并发写入保护，以及真实工作台筛选表达式与单事项进度隔离测试；随后追加未预约关联阻断专项。未做生产多岗位页面验收，不把测试当作实际客户预约。
