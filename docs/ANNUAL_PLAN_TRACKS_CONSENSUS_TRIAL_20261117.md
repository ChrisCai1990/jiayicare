# 年度方案三栏与共识试用

范围：沿用 `annualFlowPilot` 的金娟名单。其他客户继续原年度方案页面及生成流程。已发布方案不自动重写、删除或重新派单。

## 顾问视图

年度方案首屏按医疗服务、健康管理、年度体检呈现。医疗服务收拢专家就医／进一步检查、完善检查、定期复查；单学科门诊和多学科会诊仍使用各自已有执行模块。健康管理列出营养、运动、疫苗、日常监测及健康认知与共识。同一问题产生的不同专业行动仍是独立事项，可分别打开原编辑器。无来源关联的旧事项显示“来源与目标待核对”，不猜测归属；其他旧模块保留在待核对区域。

试点 AI 年度草稿不再输出日常监测模块。既有建档系统提醒和已确认方案记录不迁移。年度方案只说明监测来自现有每周接续安排；客户确实不用 App／小程序时，顾问明确勾选后为血压和体重建立同一条健管专员内部每周任务。健管专员在一次提交中录入两项实测数据，分别写档，两项完成后从实测日期接续下一周。存在未完结的旧单项人工任务时阻止重复建立，旧任务仍可按原方式完成。没有人工确认就不建立该任务。

## 健康认知与共识

十个主题为可调整的建议序列，不等于强制十次沟通。已确认方案可由所属顾问试用补入：填写客户理解、顾虑、主题序列、方式、频率和首次日期，留痕更新方案。首个主题只建立一条内部顾问任务；每次进展选择继续当前主题、进入下一主题或结束计划，保留沟通记录和下一次时间。客户端不出现这条内部任务。方案中的原就医、营养和复查任务保持原有去向。

沟通方式选择电话、到店、上门。已发布方案的原事项只读，顾问从事项旁“修改本项并保存”进入留痕修订；未发布草稿顶部及底部均提供保存入口。

顾问可在已确认的年度方案中勾选共识主题、指定本次先沟通的主题，并单独保存内部草稿。草稿不进入客户方案，不生成任务或通知；再次打开可继续修改。确认安排首个主题才把共识安排写入方案并建立一条内部任务。已发布方案顶部提供“修改方案”入口，定位到留痕修订。试点服务类型由现有模板匹配逻辑确定，只在页面右上角显示，不再提供中部切换卡片；未匹配时明确显示待匹配。

## 验收边界

上线只是开放试用入口，不代顾问选主题或勾选客户不用客户端，不自动修改金娟既有 11 项年度安排。顾问仍需核对原方案的来源问题和目标。就医、复查与营养同源多行动的完整自动分类留待顾问确认真实来源后验收；没有来源关联的旧记录继续明确提示待核对。
