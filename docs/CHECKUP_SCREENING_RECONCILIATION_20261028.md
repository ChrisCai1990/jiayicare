# 已审专项筛查核对体检方案项目（2026-10-28）

体检方案进度和五维分析前置条件统一以逐项状态、所关联报告及报告审核状态判断。仅修改方案总状态、工作台计数或专项筛查归类，不会解除五维分析门槛。

## 核对规则

- 同一客户、方案年度内已审核且非仅留存的检查报告可作为证据。门诊病历、住院病历、处方、问卷和其他客户资料不参与。
- 自动核对只处理待完成且尚无报告关联的项目，并要求报告检查日期与方案体检日期相差不超过45天；未填写体检日期交人工。报告里必须有项目实际结果；名称或医嘱名称完全一致，或项目库分类与已人工确认／高置信度筛查分类一致，且候选报告唯一。重复方案项目、重复报告或低置信度归类交人工。
- 自动写入项目 `completed`、报告 ID、时间及来源；已完成项目和人工关联不被覆盖。报告审核后尝试核对；历史已审报告可在方案详情点击“核对已审专项筛查”触发。
- 方案制定人或客户当前所属健康顾问（均须有方案编辑与年度体检方案权限）可核对。人工核对须选择本客户、本年度已审核检查报告并填写说明，记录操作人与时间。报告退回审核或仅留存后，工作台和五维分析均不再把该项目视为完成。
- 不批量回填生产客户数据；现有已审报告需由有权限人员在具体方案中显式触发历史核对。
