# AI 隔日随访三次无回应转人工

仅对**开启 `AI_NO_RESPONSE_FOLLOWUP_ENABLED=true` 后新建**、来源于已确认年度方案个性化标准随访、且方案冻结的服务包规则精确为“连续3次（隔日）未配合转人工”的任务生效。既有任务、体检/血压/用药/复查督办等提醒不回填、不改排期。

执行日发第1条，48小时后若客户没有主动留言发第2条，再隔48小时发第3条；第3条后再给48小时回应窗口。客户在任何站内消息频道或 AI 对话主动留言，停止该轮提醒。仍无回应时，以原随访为来源生成唯一一条健管专员人工跟进任务，进入现有个人工作台；这条内部任务不进入客户待办，也不能由客户完成，人工记录联系结果并按现有随访流程处理。

消息用任务 ID 与次数作为幂等键；人工任务用原任务 ID 派生固定 ID，重启或重复扫描不会重复创建。原随访完成、取消、停用、无负责人或服务期不允许执行时不继续发送。每日最多扫描100条到期任务，余量次日继续；开关关闭时扫描不读写这些任务，也不会为关闭期间生成的任务补标记。

本批仅本地实现和合成专项测试，**未开启生产开关，也未对真实会员发送消息**。上线启用前应先在隔离环境验证消息到达、回复识别、工作台可见、人工完成，以及停用/重启行为；生产启用宜先按既有健康管理客户白名单小范围观察。
