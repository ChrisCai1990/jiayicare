# 专病来源与归档状态修复

问题：原入口跳到全量资料，仅检查report.healthCourseDraft.status，未核对实际时间轴来源，已归档病历可能继续显示提取或待审。

修订：以courseEntries的sourceReportId/sourceReportIds为准。已归档直接只读查看；AI生成和提交审核时发现已归档直接返回原记录，工作台不再显示对应重复待办。新入口区分未关联病历和本专病已归档，带入当前专病供确认，上传单独打开原上传表单。

历史手工记录没有来源ID时不猜测匹配。顾问查看原始病历后可选已有诊疗记录，仅补关联并留操作人/时间，不新增记录或改临床原文；需要同客户已审核病历、权限与CAS校验。来源关联进入阶段概要证据范围，旧概要保持原快照。

27项专项（实际路由、权限/防重/CAS、已归档无AI调用、组件只读行为）及Staff构建；发布状态以日志为准。不批量迁移，不代客户执行关联、审核或AI生成。
