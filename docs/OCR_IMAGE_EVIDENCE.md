## 用户可见行为

- 纯医学影像、波形和测量标记页保留原件，显示“影像资料页 · 无文字检查结果”。不生成所见、诊断或正常判断，也不作为识别失败。
- 图文混排页只接受有对应文字原文的结果；无法对应或文字不清晰时提示人工核对。
- 审核页将纯影像页标为“影像资料”，关闭该页补提按钮；零检验项不显示“检验值未见异常”。没有文字报告时，提示补充报告或由医生填写。
- 单页补提确认纯影像页后，只更新页级提示，不修改、删除或重新归类已有结果。历史内容仍须人工核对处理。

## 实现

`backend/src/utils/reportImageEvidence.js` 是整份 PDF、图片、单页补提及各类自动复核共用的视觉解析包装器。

1. 对影像报告、含影像标记或叙述性候选的页面，单独调用视觉模型转录图外检查文字。转录请求不接收上一轮候选，排除机器参数、测量标记及基本身份信息；程序再过滤明确的页眉、页脚和机器参数行。
2. 确認只有图像且没有检查文字时，程序强制 `items=[]`、`pageType=image_only`，同时清空生成摘要。改变候选的 `itemType` 不能绕过已确认影像页的拦截。
3. 图文混排页按完整文字分句比对候选所见、诊断、结论；保留小数、左右侧和否定词。匹配失败的整条候选不进入草稿。不能用普通子串包含判断，否则“见异常”会误匹配“未见异常”。
4. 转录响应无效或调用失败时不返回未经校验的候选。文字不清楚为 `needs_review`，不能当成纯影像页。
5. 每个任务内最多缓存 24 张输入的独立转录；已确认的纯影像页不再调用后续复核。普通检验页不新增转录调用。其他触发校验的页面会增加一次模型请求，单次上限 45 秒。
6. `MedicalReport.imagePageEvidence` 保存页码、状态、拦截数量和提示，不额外存储转录全文或图像。PDF 断点格式升级为 version 2，避免旧断点中的未校验候选绕过新规则。

独立转录仍由视觉模型完成，不能保证零误判或替代医护审核；严格分句匹配可能将版式复杂、转录差异较大的真实条目标为待核对。此限制不能被描述成已解决全部 OCR 准确率问题。
