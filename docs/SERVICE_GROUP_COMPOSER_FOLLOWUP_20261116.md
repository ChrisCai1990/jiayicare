# 服务群输入区跟进（2026-11-16）

用户反馈：取消 PDF 文件选择后仍显示提交中；医护端旧页面把语音显示为占位文字；表情面板点击外部不收起，语音切换按钮占整行。

## 实施
- 仅在获得文件且开始上传时显示提交中。H5 文件选择兼容 cancel、页面重新获得焦点/可见、后续触摸以及显式取消；卸载中止监听。取消不提交资料，可重新选择。
- 医护端表情面板监听外部 pointerdown；用户端点击面板外区域收起。表情按钮和面板内选择不误关闭。
- 输入框旁用单个麦克风/键盘图标切换，保留草稿；按住说话、松开发送、上滑取消不变。

## 语音只读诊断
