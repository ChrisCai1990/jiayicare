# 明大机构接入：配置阶段

- 平台“服务机构”列表支持按机构名称、签约企业全称和标识搜索，详情进入机构服务与收费页。
- 明大保留独立机构 `mingdahealth`，服务范围拟为管理后台与医护端。客户小程序需另行上线。
- 配置阶段 `setup` 仅开放明大自己的企业信息、部门、岗位权限、员工账号、团队及套餐核对。嘉医汇现有后台和医护端维持原流程。
- 明大医护账号可登录并看到自身机构和岗位；患者、报告、随访等客户业务接口在配置阶段由后端统一拒绝。客户端也显示配置提示。这是数据隔离验收前的安全边界，不代表客户业务已开通。
- 旧嘉医汇企业信息 1 条、部门 4 条、岗位权限 13 条已先备份，再归属嘉医汇；明大从空白维护。迁移脚本 `scripts/migrate_tenant_settings_remote.py`，备份集合前缀 `tenant_settings_backup_20261002_`。
- 正式启用明大业务前，须逐一完成客户关联模型与所有 Admin、医护端接口的跨机构隔离验收，特别是服务记录、变更日志与历史客户引用；当前不能把机构状态设为 `active`，也不能将嘉医汇客户迁给明大。
