# 人工工作台可靠性修复（2026-09-29）

基线 d56fccf9；分支 fix/workbench-reliability-20260929。本轮代码已修复并验证，尚未部署。

## 已修复

1. 普通随访：人工任务、自助提醒排除、执行人搜索、时间分类均在服务端分页前处理；包含 planned / in_progress / missed，返回准确分类计数。服务等待项保留独立进度分页入口；任务减少时自动夹取有效页。不改变原权限和负责人范围。
2. AI 汇总：读取详情/生成结果时附加只读内容版本指纹；编辑及审核按所见指纹定位，数组插入不改变目标。内容已变化、旧页面缺版本或重复记录无法唯一定位时返回 409，要求刷新核对。数据库条件更新防止读写期间覆盖并发修改；长时间生成同样保护期间发生的审核。旧结构无需迁移；审核历史年度不回退最新年度镜像。
3. 请求可靠性：不适主诉和 AI 面板共用同一个查询；月度复盘、随访和订单具备加载/失败提示及重试。页面恢复、焦点恢复及 30 秒轮询刷新；同一资源串行请求，旧账号/旧筛选响应丢弃，处理完成前发出的旧响应不会复活任务。
4. 历史风险：按全部年度列出未审核预警，以客户和年度区分待办，链接明确选择风险年度；某年度审核后只移除该年度任务。
5. 订单：通过现有接口逐页完整读取待办与历史预约，包含进行中及未来提醒，保留与服务进程合并去重后的每页 5 项展示；任一接口页失败，显示列表未完整加载，不将部分数据当成功。订单目前仍是完整读取后合并展示，未改为跨来源的服务端订单聚合接口。
