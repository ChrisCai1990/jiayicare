# 就医偏好与预约安排（2026-09-22，本地修订）

## 已实现

- 医护客户基本信息编辑复用 `residence.city`，新增 `carePreferences.city/hospitals/allowTravel`。可多城市、医院文字记录；异地意愿为空不视作同意。首选城市空时动态沿用常住城市，不覆盖省区。
- 偏好选填，不增加年度准备门槛。年度生成提示引用偏好并进入输入指纹；无核实医院库不猜医院。App/小程序本轮不新增录入界面，沿用共享 User 数据；不更改客户自填接口。
- 新生成就医/完善检查/复查及年度体检可给具体建议日期、原检查基准、月间隔、依据及科室，顾问审核。按日历月换算（月底截至目标月最后一天），不是每月30天。未可靠确定时不捏造；没有调用真实AI验证建议质量。
- 新日期标记 `appointmentSchedulingVersion=1`，随访日期取建议日期前7天，实际assignedTo仍是客户所属健管。来源排期key保留原就医日期。过期安排保持原到期日期，进入逾期处理，不按每日重放平移，内容提示立即安排及一周内完成预约。
- 旧记录不批量迁移、不自动提前7天；顾问编辑日期后采用新规则。原方案冻结、确认、结果结案、防重保护不变。
- 年度体检统一隐藏标准字段、自动负责人及末尾服务安排；文本框支持结构化旧重点内容逐行展示，后台来源保留。
