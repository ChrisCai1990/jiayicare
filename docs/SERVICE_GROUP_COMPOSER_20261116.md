# 服务群自动分类、语音与输入习惯（2026-11-16）

用户确认：客户不选择医疗类别，自动识别；不确定交健管核对。保留原件、原审核门槛；不识别普通聊天或家庭测量照片。上传图片/PDF仍限定同一份资料。分类逐页，单一支持类别可继续提取；体检封面/项目与检验检查组合认作体检；混合门诊处方等不猜测，留待分类。旧客户端传类别继续兼容。

语音：小程序原生MP3、H5麦克风PCM转16k单声道WAV；最长60秒、上滑取消、发送前可取消/发送原语音/转文字。转文字需原语音客户speech授权，结果插入草稿可编辑。已发送语音在医护/客户端及历史查询可播放、转文字；转换不触发AI、不写健康档案；原语音不会按占位文本触发AI回答。语音API沿用群租户/成员/归档限制，监管读取记录审计。

移除独立@按钮，文本输入@弹成员列表，保留小嘉与角色标签并关联真实成员ID。表情面板提供通用Unicode表情，可与文字一起发送。

## 六项确认后的补齐

- 医护端也支持录音发送及发送前转文字；原语音及语音识别仍执行群权限、原有 speech 授权限制。
- 引用单独使用 quotedMessageId（不能复用 AI 去重的 replyTo）。后端校验同群同机构，摘要来自原消息；允许多次引用同一句。手机长按、电脑消息右键菜单选择引用，发送前可取消；点摘要查看原消息上下文。
- 企业微信群提醒沿用一对一提醒的应用配置与绑定关系。仅新客户群消息（含语音、资料）标记 eligible，不批量补发旧聊天。每群每接收人员按一分钟窗口合并，10 秒扫描队列。发送前再次核对实际入群、客户归属、在职与模块权限；监管人员不默认接收。AI 回复不取消提醒。
- 企业微信仅发送通用新消息提示和需登录的群链接，不发送姓名、病情、语音或报告正文。领取队列后网络结果不确定时不自动重发，失败留存运维检查，避免重复消息。链接按 groupId 请求授权范围内的单群，不受列表分页影响。
- 本地验证包含隔离 Mongo 的语音、引用、合并去重、成员撤权测试；浏览器使用合成麦克风和合成接口。真实手机录音、微信长按与企业微信实际到达需用户使用验收，不能将构建通过视为真机完成。

测试：真实隔离Mongo验证上传归属、未知类型、原件去重、语音组权限/租户边界/授权/缓存/只展示不写记录；分类逐页及异常响应、音频格式/长度/时长测试；浏览器合成麦克风验证录音、转文字草稿、发送和@/表情/上传。发布与真机结论以release-receipts/group-composer-*为准，未将构建通过视作真机完成。
