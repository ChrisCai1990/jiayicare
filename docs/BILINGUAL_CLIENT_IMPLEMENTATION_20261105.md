## 大陆与海外手机号关联同一客户

目前 `User.phone` 是唯一手机号，`/send-code` 只接受大陆 11 位号码，`/login` 按手机号查找并在找不到时创建新 `User`。因此新号码现在不会自动关联既有客户。

目标方案：以不可变的 `User._id` 作为客户身份，增加多个已验证的登录号码（统一 E.164 格式、各号码唯一），区分主要号码与备用号码。登录后的客户从账号安全页发起绑定，新号码完成验证码验证后才能加到该 `User._id`。登录查询号码索引，两个号码返回同一 `User._id`。换绑、解绑和遗失原号码需要额外身份核验及审计；不得仅凭同名、微信昵称或地区自动合并两份客户记录。

如海外号码已经注册了另一 `User`，绑定应返回冲突并转人工核对；既有报告、家庭授权、订单、支付和权益的合并必须单独设计迁移及回滚，不能简单移动手机号。国际短信渠道、区号支持、送达率与费用须在实现前确定；当前阿里云短信调用和前端均面向大陆号码。
