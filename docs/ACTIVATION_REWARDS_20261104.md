# 激活奖励与赠券展示修复（2026-11-04）

## 规则

- 客户完成实名建档激活后，奖励基金 100 元；`firstLoginFundGrantedAt` 防止重复。已激活客户不因再次登录批量补发，需按流水单独核对。
- 客户首次成功提交本人健康问卷后，另奖励基金 50 元；`firstQuestionnaireFundGrantedAt` 防止重复。邀请好友完成问卷的奖励仍按原独立规则处理。
- 两笔金额及开关可在 Admin 健康基金规则中配置。新配置默认启用 100/50；已有生产配置中的显式关闭或 0 元仍生效，发布前须只读核验。

## 展示

- 医护客户“会员权益”增加单独赠送服务与优惠券记录，展示剩余次数、有效期及状态。小程序“健康服务”摘要也接入赠送服务记录；服务包摘要和单独赠送记录分开展示。
- 赠送记录属于客户，使用资格还要由具体服务流程校验。就医协助使用时，后端核对赠券名称、有效期、剩余次数，并把 `giftRecordUsage.giftId` 写入履约订单；这条订单关联才是服务使用链路的依据。门诊一站式赠券现可从医护端选同名方案，建立 0 元履约单和关联方案；不把赠送备注视为已核实付款。
