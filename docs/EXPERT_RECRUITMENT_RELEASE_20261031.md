# 专家招募第一批发布候选

## 范围

本批仅包括专科合伙人发起专家邀请、专家手机填写一次性线上问卷、Admin 查收并核验专业/沟通/品德/资格、确认合作报酬和关联医护账号后入专家团队库。管理端入口为“专家招募与问卷”；问卷链接只显示一次，有效期 14 天。问卷不收客户资料和证件照片。新专家默认可作为后续派单候选，但本批没有客户下单、自动派单或会议功能。

全岗位排班、预约、转介信和腾讯会议代码均不在此发布候选中；第二批待订单与已有预约统一接入后上线。

## 验证与发布门槛

- 独立 MongoDB 7 合成资料测试：问卷仅提交一次、机构后台数据隔离、准入核验和入库后的机构归属均通过。
- Admin 构建通过；现有医疗资源库回归测试通过。
- 发布前必须从 GitHub 核对最新 `master`，整合并复测；正式部署链要求先成功推送同一提交到 GitHub，再将 bundle 部署到阿里云。
- 当前 GitHub 连接返回账号暂停，不能确认远端最新版本或推送；当前 SSH 客户端未通过生产主机密钥校验。此候选不能以本地 `origin/master` 直接代表生产最新版，也不能绕过标准链路上线。
- 发布后使用测试专家邀请完成一次端到端验收：创建链接、手机填写、后台查收、核验入库、专家库显示。验收不使用真实客户资料。

## 回退

管理端入口可通过回退本批代码移除；已收集的专家问卷和入库资料需保留供人工核对，不能仅回退代码就删除数据。回退应按标准 Git 提交、推送、部署流程执行，并再次检查 API 健康和原有医疗资源库。
