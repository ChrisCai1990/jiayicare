# 服务群医疗资料 2026-11-16

范围：整份体检报告、检验报告、检查报告、门诊病历、处方。用户在服务群选择类别，上传同一份资料的1–9张图片或单个PDF，总计不超过15MB。多页PDF超过50页留待人工处理。

原件自动保存为当前客户的一份 MedicalReport（原始资料），群消息关联原件，健管专员可进入现有原始资料核对页。未审核不写入正式健康记录；日期留空待核对，不以上传时间充当检查日期。其他聊天文字没有识别/入档触发器。

客户健康资料AI授权有效时启动现有持久化识别队列，逐页先核验类别，无法确认/不匹配/其他照片不提取数据，仅保留原件供人工核对。整份体检报告允许体检、检验、检查页组合。未授权仍可保存原件。群来源不能借用分配员工身份绕过客户授权。

权限：本人且当前有效群；服务器再次校验群状态和成员。读取原件沿用群阅读权限，链接短时签名。来源键按客户/群/请求唯一，重试同一请求不重复创建原始资料或消息；未知写入结果先核验数据库引用再清理文件。

验证：隔离Mongo权限/跨租户/关闭群/五类资料/重复请求/未授权人工处理/已授权队列/不重复排队；分类器逐页排除其他照片及无效输出。未调用真实客户资料或模型。H5合成浏览器验证整份体检报告文件选择、提交参数、状态刷新和小屏控件。

上线状态以 release-receipts 发布回执为准。各App H5只同步本次群页面/API/组件，保留版本信息与推送改动；小程序需单独上传与微信审核发布。
