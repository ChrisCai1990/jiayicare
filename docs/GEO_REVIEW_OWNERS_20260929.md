# GEO 专业审核负责人修复

## 原因与范围

原工作台、内容列表和审核接口只检查 nutritionist / familyDoctor 岗位，导致同岗位员工均可看到和处理 GEO 稿件。GEO 不关联会员，不能用会员归属解决。

按用户指定分工，专业审核固定为蓝戈文（健康顾问）、吴苗苗（营养师）。生产只读核对三人账号标识及 active 状态后，使用稳定账号 ID 校验，姓名变更不转移权限。同名账号、其他同岗员工及停用账号不得读取审核列表或提交操作。超管督办和健康规划师最终发布流程保持。

三个入口共享 contentReviewAccess 规则：工作台聚合、列表/历史、审核提交；工作流本身也校验身份和岗位，旧页面提交返回 403。已存在任务动态按负责人展示，无需改写任务、审核结论或历史留痕。未来更换负责人须更新该显式映射并重新核验账号。
