# 市场合伙人核算与服务团队激励设计

日期：2026-11-10。状态：实施设计；正式启用以线上版本、配置和验收记录为准。

## 范围和边界

市场合伙人与现有 `Partner` 权益合作机构是不同主体。外部合伙人使用独立身份、推荐码和只读查账入口；健康顾问、营养师、健管专员使用现有员工身份。两类报酬分别记账。商城与线下合同共用订单、收款、退款及结算口径。客户健康档案和临床记录不向市场合伙人开放。

每位市场合伙人通常只授权一个产品线。名下客户购买其他产品不自动产生合伙人佣金。跨产品推荐须单笔授权且留痕。同一订单最多一位外部合伙人，订单归属快照不随之后的客户关系变化重写。购买时最后一个有效的推荐链接或码优先；手工改归属须审批。没有有效推荐，外部合伙人佣金为零。

## 产品规则

金额计算以分为单位。销售佣金基数为该订单经核对的公司现金实收减成功退款；赠送、健康基金及优惠券抵扣不进入现金计佣基数，除非特定产品合同另有经审核的规则。第三方直接收款不自动计佣。

| 产品线 | 首次或首年 | 后续 |
| --- | --- | --- |
| 365会员 | 20% | 第2年10%，第3至5年5%，第6年起0 |
| 年度顾问、高端顾问 | 当月有效新客1位10%、2位15%、3位18%、4位及以上20% | 第2年8%，第3至5年5%，第6年起0 |
| 体重管理 | 当月有效新客1位8%、2位10%、3位12%、4位及以上15% | 后续周期0 |
| 慢性病管理 | 首次10% | 后续周期0 |
| 单次就医协助 | 合伙人亲自促成的首次15% | 复购0 |
| 一站式就医 | 首次10% | 复购0 |
| 单次评估、心理咨询、运动复健 | 每次10% | 同一客户后续购买仍为10% |
| 检测、营养素补充 | 按产品单独配置 | 未配置时0 |

年度序号以同一服务对象、同一产品线的有效付费服务期排序；提前续费和补款不增加序号，中断不重新从第一年计算。个人和家庭年度产品均按一位新客计算；体重管理按服务对象人头计。同一客户同一产品当月只计一位，续费不计首年阶梯。月度阶梯按自然月、合伙人和产品线汇总线上与线下订单，30天留存后最终确认，档位作用于当月全部合格订单；退款或经审核的服务终止触发重算与差额流水。

年度顾问、高端顾问、体重管理、慢性病管理的首次方案沟通至到账不超过7个自然日，若规则启用，额外奖励1%，单笔最多1000元。365、就医协助、一站式、单次评估、心理咨询、运动复健不适用；续费不适用。首次沟通时间必须来自不可回填的业务事件，不能靠结算时手写日期。

企业留存目标或底线逐产品版本化配置，默认不设全局固定比例。后台试算同时展示公司净收入、履约直接成本、服务团队变动激励、合伙人佣金、交易成本和预计留存。规则不足或成本不全时提示人工复核，不静默改合同佣金。

## 收款、计提、发放与冲回

商城订单由已验证的支付流水确认到账；线下合同登记后必须由财务核对收款凭据，审核前不计佣、不计阶梯。线上线下不得凭订单状态或人工备注推断现金已收到。退款按实际成功退款流水，部分退款同比调整百分比佣金。

到账后生成预估佣金，不在当天发放。实际服务启动且支付满连续7天后，第一笔最多可审核发放确定金额的50%；支付满30天且无退款、无正式服务终止后审核余款。月度阶梯的首笔以最低档暂估，相关自然月全部订单经过30天观察期后重算并补差。结算按分取整，差额进下一结算单。刷单或虚假转化经审核可全额冲回。已打款事实不可覆盖，以新的冲正或待追回流水表示差额。

“30天内流失”仅限有依据的服务终止或合同解除，须运营和财务审核；未登录、未回复、暂停或投诉不自动判定。订单、佣金和结算的每次状态变化均记录事件、操作人、时间、原因和规则版本。

## 服务团队激励

健康顾问 `familyDoctor`、营养师 `nutritionist`、健管专员 `healthManager` 可参与任意服务。管理后台按产品/规格/岗位配置百分比或固定金额、计提节点、生效时间、可选封顶与产品留存目标。未配置的岗位不产生激励。订单或服务任务冻结当时生效的规则版本；金额属于完成并验收该节点的具体人员，不能仅凭岗位默认人自动发放。团队激励和合伙人佣金使用不同账目和审核状态，财务视图汇总成本。已有内部员工转介绍佣金规则继续独立，禁止同一订单同一贡献重复计提。

## 数据与页面

新增市场合伙人、推荐码/链接、客户归因事件、产品佣金规则版本、线下合同订单登记、外部佣金流水、月度阶梯快照、团队激励规则/流水、结算批次和审计事件。所有归属、规则、金额和状态有稳定唯一键及版本；重复支付回调、重复退款通知和重复批处理只产生一次账务事件，重算通过差额流水冲正，不能覆盖历史记录。

管理后台提供合伙人审核、产品授权、佣金和团队激励规则、线下收款核对、试算、结算审核、导出和审计。合伙人独立手机入口提供推荐链接、名下客户交易摘要、逐笔佣金计算依据、状态和月度阶梯。客户小程序只补推荐码入口、登录后保留来源和下单提交来源；后端重新验证来源，不能信任客户端提交的合伙人ID。

## 2026-11-11 结算续做

## 2026-11-11 首次沟通证据与索引门槛

首次沟通由管理端当场登记、服务器记时且不能回填；另一管理员复核通过后，新订单冻结首次事件及亲自促成事件 ID，供单次就医直荐比例及七天奖励计算。没有可核证事件时这两项不自动发放。订单创建前后更改事件不反写已冻结的归属快照。

生产可设置 `STARTUP_SCHEMA_WRITES_ENABLED=false`，因此新增唯一索引不能依赖自动建索引。已加入索引核对脚本 `backend/src/scripts/marketPartnerIndexMigration.js`：默认只列缺口，只有明确设定 `MARKET_PARTNER_INDEX_APPLY=true` 才建索引；启用 `MARKET_PARTNER_ENABLED=true` 时后端启动会检查索引，缺失则拒绝启动。尚无可用隔离 MongoDB 实测索引创建和并发收款/退款；这仍是上线阻断项。

管理端侧栏仅在本机构合伙人 API 可用时显示“市场合伙人”，默认关停阶段不暴露空入口。本地未找到 `mongod`、Docker 或 Podman；20 项定向测试、管理端构建和后端语法检查通过，不能替代真实数据库及小程序审核验收。
