# 年度研判与执行流程统一（2026-10-07）

## 业务规则

资料上传、AI解析、健管专员审核后，由健康顾问审查。年度研判须有近12个月已审核体检，以实际检查日期判断，门诊和单项复查不代替年度体检。近一年用于当下就医及复查判断；近五年用于趋势及检查完整性评估。客户筛查结果解读与年度方案确认是不同环节。

医疗安排分为需要安排就医、需要完善体检、需要定期复查、年度体检。目标承接已确认研判；医院只沿用有依据的对应记录，已录入的医院科室专家在匹配同一事项重新生成时保留。无来源字段留空。

健管专员预约、随访与结果回收；健康规划师督办；就医协助团队执行代办、代诊、陪诊。营养继续使用既有评估和方案生成流程，研判中明确的营养相关指标自动提取，不自动填写未经核实的医疗数值目标。

## 本次代码

- annualReviewEligibility：两个年度创建入口及年度AI讨论入口的近期体检准入；准备清单同步展示。
- 年度讨论增加五年已审核体检资料，避免仅最近30份资料挤掉早年体检。
- annualArrangementHistory：精确报告来源对应机构、上次年度体检机构预填；不猜测专家。
- 新确认方案标记checkupPreparationVersion=2，原确认方案不批量迁移。
- 新版体检准备：30天健管专员准备和规划师督办；7天健康顾问定制。新发起体检服务预约任务归健管专员。
- 体检问卷复用已配置且唯一的在售体检服务问卷，确定性推送ID防重复；答卷显示在准备任务。配置不存在或冲突进入顾问异常提示。
- 年度体检间隔为12个月，准备时间独立计算，不再把提前准备当作体检日期。
- 新版四类事项仅提醒模式也有规划师督办；已有关联服务任务保留。
- 已关联管理问题的执行表单隐藏重复目标及空白完成标准，真实已有完成标准保留。

## 验证和运行边界

使用合成单元测试及独立服务器临时工作目录构建验证，不自动生成真实客户AI方案，不自动确认或发布客户年度方案。体检自动准备受CHECKUP_PREPARATION_AUTO_ENABLED和客户健康管理开放范围共同控制。旧确认方案与历史任务不自动重排。

商城入口和独立营养入口复用既有实现，本次没有重建商品、订单或营养专业方案规则。心理、运动康复、中医不在本次范围。

验证：108项相关合成测试通过，Staff生产构建通过。线上核对启用前历史自动准备方案为0、体检问卷配置为1；新开关只为之后确认的方案写入自动准备标记。
