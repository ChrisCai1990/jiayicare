# 儿童健康档案分龄设置

## 规范依据

- 0～6岁采用《国家基本公共卫生服务规范（第三版）》的四类记录结构：新生儿家庭访视、1～8月龄、12～30月龄、3～6岁儿童健康检查。官方文件：[国家卫生健康委通知](https://www.nhc.gov.cn/jws/s3578/201703/d20c37e23e1f4c7db7b8e25f34473e1b.shtml)。
- 在校儿童采用《中小学生健康体检管理办法（2021年版）》规定的年度体检项目；该办法要求各省制定学生体检表，因此系统提供项目记录结构，不声称存在全国统一的学生体检表。[国家卫生健康委、教育部通知](https://www.moe.gov.cn/jyb_xxgk/moe_1777/moe_1779/202110/t20211027_575478.html)。

## 数据流

1. Admin 创建儿童健康问卷，逐题设置适用年龄段。未指定年龄段的题目属于所有儿童的共同背景信息。
2. 会员端依据已核实出生日期展示适龄题；提交时服务端再次计算年龄，过滤非适龄答案，并冻结题目及年龄段快照。没有有效出生日期时，儿童问卷不能推送或提交。
3. 首次答卷仅预填儿童基础档案的空字段，所有导入项待医护核实；后续答卷只形成变化待确认项。出生史、家族史和日常情况属于监护人报告，不能自动充当访视或体检结果。
4. 医护端另行按规范表类、实际检查日期和节点记录客观检查、评价、指导与转诊信息。记录保留资料来源、录入人和依据；修订时追加新版本，旧版本继续可查。

## 口径

- 问卷阶段：新生儿（未满28天）、婴儿（28天至未满1岁）、幼儿（1岁至未满3岁）、学龄前（3岁至未满6岁）、学龄（6岁至未满12岁）、青少年（12岁至未满18岁）。这是问卷显示分组。
- 规范表类按实际访视节点选择。3～6岁标准表包含6岁节点，因此问卷显示为“学龄期”的6岁儿童仍可录入该标准表。学龄期年度体检仅用于实际在校儿童。
- 页面中的标准项目记录支持按实际已取得的资料逐项录入；空项表示未记录。它不替代正式签署的检查报告、地方学生体检表或公共卫生平台报送。
- 历史答卷若在本次改造前提交，没有年龄段快照，显示“年龄段未记录”；不按儿童当前年龄倒推历史。
