# 专家合作问卷验收修订

用户验收指出：原邀请链接只供一人填写且只显示一次，不便专科合伙人转发给团队中的多位专家；问卷首页有无关提示，服务准备题意不清，报价输入框因条件隐藏而不明显。

本次新增“专科团队可转发链接”：Admin 按合伙人和专科团队生成，链接可反复复制并转发；多位专家分别提交，后台逐份查收。同一链接下，同一手机号只能提交一次；Admin 可停用链接。原单人邀请链接仍可按原规则使用，不删除既有问卷或已完成审核。

问卷首页删去与当前字段无关的提示；会前阅资料时间、资料量上限、书面回复时限、报价工作项从问卷移除，留待合作条件沟通。单次咨询与 MDT 的每次预期报酬输入框始终显示，说明包含约 15–20 分钟线上交流、必要资料阅读和书面回复，勾选合作方式时相应报价必填。Admin 查收页分别显示两类报价及税前/税后口径。

验证以隔离 Mongo 合成资料测试为准：旧链接仍只可提交一次；新链接可由不同手机号提交、同一手机号重复提交被拒、跨机构不可查看、停用后不可继续提交。发布后需核对线上 Admin 页面、公开问卷和 API，不使用真实客户资料。
