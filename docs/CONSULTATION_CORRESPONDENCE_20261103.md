# 专家转介补充资料往来

- 专家在已派发、尚未提交正式回复时提出补充要求；负责健康顾问收到工作台待办，沿既有工作台提醒显示。
- 顾问可回复补充信息或明确暂无资料。报告沿原转介信修改/补充入口选择，不扩大专家客户档案权限。
- 每条提问与每次回复追加保存人员、时间及回复时转介版本；回复后顾问待办消除，专家仍有正式回复待办。
- 未答复要求不允许结束正式回复；结束服务后往来只读。
- 客户转介档案直接关联读取同一咨询记录的全部往来、正式回复及历史版本，无双写同步风险。不自动写入医疗诊断或已审核专病病程。
- 隔离 Mongo 流程测试覆盖权限、待办、追加记录、正式回复闸门与档案关联；组件测试覆盖档案完整展示和编辑入口。
- 本文件为实现记录；上线状态以部署回执为准。
