# 账号注销与数据处理规则草案

2026-10-27。用户已确认“没有现成规定”。用户进一步确认：系统只保存客户报告副本和健康管理记录，不承担正式病历保管。用户另已确认：系统是订单、支付、退款记录的唯一保存位置；没有另外上传的发票PDF或会计凭证图片。不能把这些交易记录直接称为会计凭证，也不再把不存在的发票文件作为注销前置条件。客户报告副本和健康管理记录按本人普通个人数据纳入删除范围；不套用医疗机构病历保管年限。这是待落实到各类真实数据的方案，不代表已经发布的隐私政策或已经实施的销毁制度。不能仅设置环境变量就称为注销整改完成。

## 拟采用的产品行为

- 用户在“我的 → 账号安全 → 注销账号”阅读影响说明并确认，无需先打电话、发邮件或另外提交普通反馈。
- 说明注销影响同一身份在 App 和微信小程序中的登录与个人数据访问（两端共用后端）。注销不会撤销医院保管的独立原始病历，也不会注销其他家庭成员的账号。
- 提交申请后显示申请编号和真实处理状态，完成后出具可在退出登录后查看的回执。处理时限须在清理执行器及运营承接验证后确定并公示；目前不承诺“立即完成”或未经实施验证的固定天数。
- 注销完成后，原手机号/微信标识再次注册是新账号，不恢复旧健康档案、聊天、照片或分享链接。
- 未完成的退款、商品交付或真人服务分别处理，不能仅因有服务包就无限期拒绝接受注销申请；不能擅自把注销当成客户放弃退款或服务权益。

## 已核对的官方依据及适用边界

1. 《个人信息保护法》第四十七条规定了删除情形及法定保存期限未届满等情况下的处理限制。不能因为历史系统设计成软删除，就把永久保留视为合规。
   https://www.cac.gov.cn/2021-08/20/c_1631050028355286.htm
2. 《电子商务法》第三十一条的三年要求针对电子商务平台经营者。当前只确认嘉医汇通过微信小程序销售自身商品/服务，未证明其属于该条平台经营者；因此不能直接给所有订单硬编码“三年后删除”。
   https://www.cac.gov.cn/2018-09/01/c_1123362506.htm
3. 财政部对《会计档案管理办法》的解释区分主要会计档案与辅助资料，主要会计凭证/账簿最低期限为30年、其他辅助资料为10年。要按真实会计档案分类适用，不能扩大为全部 App 数据。
   https://tfs.mof.gov.cn/zhengcejiedu/201512/t20151214_1613341.htm
4. 《医疗机构病历管理规定（2013年版）》第二十九条针对医疗机构保管的门急诊/住院病历，分别规定不少于15年/30年。不能仅凭“健康管理”或“医护端”名称套用到所有客户上传报告。
   https://www.nhc.gov.cn/yzygj/c100068/201312/c9955f0471c04450a9f9ab74648fbdd4.shtml
5. Apple 要求提供整个账号及其相关数据的删除；法定留存项目应告知。合理时限的人工/异步处理可以接受，但不能只停用账号。
   https://developer.apple.com/help/app-review/guideline-reference/5-1-1-account-deletion

以上是实施准备与适用性核对，不是对本公司全部法定义务已完成认定的结论。
