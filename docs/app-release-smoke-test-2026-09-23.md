# App 上架前冒烟测试清单

适用版本：完成 APP-001 至 APP-003 后的 App 包。执行人须分别使用新安装访客、普通已登录用户和有订单/档案数据的账号验证。任何 P0 失败均不提交应用商店。

## 访客路径

| 编号 | 操作 | 预期 |
| --- | --- | --- |
| G-01 | 清除 App 数据后冷启动 | 直接进入首页，不强制登录 |
| G-02 | 查看首页服务卡和全部商城 | 服务目录可加载；不因无 token 出现错误或空白 |
| G-03 | 点击健康档案、健康管家、我的，或首页头像 | 进入登录页，不展示他人或空壳个人数据 |
| G-04 | 在商城点击预约或购买 | 进入登录页；未创建订单、未提交预约 |
| G-05 | 在商城返回首页 | 返回正常，无循环跳转 |
| G-06 | 查看用户协议和隐私政策 | 可打开、内容完整、返回正常 |

## 登录后主路径

| 编号 | 操作 | 预期 |
| --- | --- | --- |
| M-01 | 登录后返回主界面 | 底栏为：首页、健康档案、健康管家、我的 |
| M-02 | 打开四个底栏页 | 页面和数据正常，切换无白屏 |
| M-03 | 打开个人中心的服务消息 | 消息页可达，已读/未读行为符合现有后端规则 |
| M-04 | 首页进入健康打卡、待办、提醒 | 均可到达对应页面并可返回 |
| M-05 | 商城查看商品、提交咨询或购买 | 登录态、价格、规格、订单和错误提示正确 |
| M-06 | 健康档案上传报告、查看报告 | 上传授权、错误处理和数据展示正确 |

## 隐私和稳定性

| 编号 | 操作 | 预期 |
| --- | --- | --- |
| S-01 | 首次上传体检报告 | 仅操作时请求相机/相册权限，说明与隐私政策一致 |
| S-02 | 拒绝相册或相机权限 | 保留可理解的替代操作和错误提示，不崩溃 |
| S-03 | 弱网打开首页和商城 | 骨架/加载/失败态可见，可重试 |
| S-04 | 退出登录再回到首页 | 不显示前一用户健康信息；访客首页可用 |
| S-05 | 账号注销流程 | 可找到入口，提示、确认、结果和再次登录行为符合政策 |

## 通过判定

- 所有 G 组、M 组和 S 组案例通过。
- 无阻断性崩溃、白屏、敏感信息泄露、无法返回或错误创建订单。
- 对比小程序，服务名称、导航名称、关键入口和登录拦截一致。
