# 家庭档案切换与报告归属（2026-10-13）

小程序健康档案页可在本人和本人直接监护、仍未成年的同机构孩子之间切换。当前对象以登录账号 ID 为作用域保存在本机；每次进入档案或上传页都重新读取监护关系，关系失效时清除选择。切到孩子后只展示儿童基础档案和该孩子的报告入口，不展示母亲的健康趋势。

常规报告上传页显示所属档案并在选择文件前再次确认。`POST /api/reports` 的 `patientId` 为可选字段，缺省兼容本人；指定孩子时服务端用直接监护关系校验，报告 `user` 写孩子、`submittedByUser` 记实际提交账号。列表、分类、详情、原件、解析和删除按同一权限判定；普通成年家庭关联不授予健康资料访问权限。历史报告不自动迁移。

小程序服务商城原有服务对象选择继续保留；若当前切到孩子，结算默认选该孩子。结算前仍验证服务对象，订单归服务对象，付款人与退款申请人保持当前登录账号。退款继续关联原微信支付单；不随当前档案切换改变。

本变更只涉及小程序常规报告与已有家庭下单链路。App 客户端目前没有家庭服务对象下单流程，不能把小程序的当前档案选择误当作 App 已同步。发布需要后端与小程序配套，微信真机核对母亲/女儿上传、查看、下单与退款权限。原有误传资料需核对原件后人工纠正，不自动移动。
