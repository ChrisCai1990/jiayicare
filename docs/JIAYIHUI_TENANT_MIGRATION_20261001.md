# 嘉医汇机构归属迁移

2026-10-01 生产只读审计：当前没有 Tenant；1,387 位客户、25 个管理员账号均未标机构，其中 1 个为平台管理员，因此需迁移 24 个机构员工账号。2,264 份体检报告、141 笔订单、1,504 条健康记录及其他有 tenantId 字段的业务记录也均未标机构。审计只读取数量，未读取客户明细、未写生产库。

业务方确认目前全部客户属于嘉医汇。登录代码在迁移窗口内兼容未标机构的旧账号，新注册账号直接归嘉医汇。

## 发布顺序

1. 暂停生产写入，建立并核验数据库备份。
2. 在与生产同版本的代码上运行 `node backend/src/scripts/assignJiayihuiTenant.js` 预检，核对全部集合数量、其他机构数量为零，并确认客户 1,387、机构员工 24（以执行当时最新预检为准）。
3. 用 `--apply --backup-confirmed --expect-users=<预检客户数> --expect-admins=<预检员工数>` 执行一次性迁移。脚本只修改未归属记录，保留平台管理员不归属机构；重复执行只处理剩余未归属记录。
4. 部署配套后端与 Admin。嘉医汇注册入口创建的客户将写入嘉医汇 tenantId，平台可从机构列表进入只读客户名册；平台访问留审计。
5. 核对嘉医汇员工/客户登录、平台看到的嘉医汇客户总数、抽样报告/订单归属及新注册客户归属。再解除写入暂停。

## 未纳入本次范围

部分旧模型没有 tenantId 字段；在开放第二家机构之前，仍须逐接口完成跨机构读写验收。平台客户名册仅显示姓名、手机号、正式客户标识和注册时间，不开放健康档案与报告详情。

外部机构新建接口默认关闭，完成验收后才可设置后端 `ENABLE_EXTERNAL_TENANTS=true` 及 Admin 构建变量 `VITE_ENABLE_EXTERNAL_TENANTS=true`。
