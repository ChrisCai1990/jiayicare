# 营养干预记录的下次随访任务

营养干预记录保存有效的“下次计划日期”后，按来源记录 ID 幂等建立一条分配给该会员所属营养师的人工随访任务。任务立即进入营养师工作台的“待随访任务”，计划日期用于今日、逾期和未来日期分组。AI 草稿须审核通过后才建任务。

修改原记录日期会更新未完成任务；清空日期或删除原记录会取消未完成任务；重新设置日期可恢复因清空而取消的任务。已完成任务保留实际执行结果，不因编辑历史记录重新打开。任务的日期、负责人和取消状态只从原记录同步，营养师仍从随访入口填写实际执行结果并完成任务。服务重启时幂等核对未来日期的既有营养记录，补齐发布前已设定的预约任务，不追溯生成过去日期的任务。

同一会员、同一自然日已有营养方案的专业阶段评估时，工作台待随访卡显示关联状态；该预约随访未完成前，服务任务区暂不再显示同日阶段评估卡。随访完成后，阶段评估卡继续出现并要求独立完成。正式阶段性健康评估的生成、审核和归档状态不由普通随访自动完成。

本次不批量改写历史服务记录或已完成的随访任务。若会员未分配营养师，预约记录保留，但不能生成有负责人的工作台任务，需先修正会员归属。
