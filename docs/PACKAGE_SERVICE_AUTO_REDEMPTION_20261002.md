# 服务包次数自动核销（2026-10-02）

- 权益来源以已购买或已生效的服务包为准；会员类型仅用于展示、筛选。共享次数按池扣一次，独立服务按对应商品扣一次。
- 年度营养访谈由营养师核实并完成后，以及营养领域的阶段性评估正式归档后，分别按对应的服务完成来源核销营养干预商品。就医类订单必须有明确的年度服务需求关联，且服务订单整体完成后才核销；单独付费订单不扣服务包次数。
- 从权益发起服务时先预占一次；履约订单完成后改为已核销，取消或退款且尚未完成时释放预占。同一完成来源用确定性键防止重复扣次。
- 历史生效但没有订单权益快照的服务包，首次新服务完成时冻结当前配置并记录新核销。历史用量未知，页面不显示确定剩余次数，人工预占前须先核对历史。异常在医护端权益卡提示核对。
- 后台扫描由 `PACKAGE_SERVICE_AUTOREDEEM_FROM`（ISO 时间）开启，仅重试该时间之后完成的营养任务与服务订单，不批量回填旧完成记录。
- 医护端“会员权益”展示已购买/生效计划；“消费记录”集中展示订单逐次核销、套餐预占与自动核销记录。历史生效服务包由超级管理员输入上线前各共享池/独立服务已用次数及核对依据，系统与上线后记录合并计算余额，并留下审计；未核对前不显示确定可用次数。
- “消费记录”将套餐包含的商品显示为 ¥0 待发起清单行，与单独购买订单并列并标明来源。次数权益本身不是订单；选定具体服务时才预占一次并创建 ¥0 履约单。营养评估仍由正式完成事件自动核销，避免同时创建独立履约单而重复扣次。
