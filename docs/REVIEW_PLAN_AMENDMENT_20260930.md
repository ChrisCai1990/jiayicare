# 研判沟通补入年度方案

AI回复下的“补入年度方案”向健康顾问和超管开放。选择已有年度方案后，按需调用一次AI，仅提取当前回复已有行动，预览中可修改、取消、选择更新现有事项。支持就医、完善检查、异常复查、疫苗四个板块，不重新生成整份方案。

保存前需顾问确认依据、建议和日期。服务端校验可见客户、方案和研判归属、消息仍存在、来源指纹及方案版本；一次原子更新保存差异与审核人、时间、原回复快照。同名事项合并，别名由顾问选择更新目标，保留既定机构、执行人、原日期及内部备注。

这是显式留痕修订入口：已发布/冻结方案不会通过普通保存被覆盖；顾问在此入口看到客户内容会同步变化的说明后，可确认局部修订。原事项前后快照保存于supplementRevisions，既有发布/确认状态保留。不会自动新增、取消或重排执行任务，成功文案明确“未创建或调整执行任务”，后续执行安排须走既有流程。再次打开可查看当前回复已补入记录。

未代客户实际生成、确认或推送。4项专项测试（含隔离HTTP权限、跨客户、过期版本、确认及审计）通过，医护端构建通过。
