# 顾问提交至专员预约

2026-11-03：用户授权修订部署。发布结果见工作区 release-receipts。

- 顾问可从 intake/advisor 阶段选择已有 pending 转介信，审核资料后一次提交至专员预约；校验负责人有效、专家类型/人数/报价、顾问归属和来源报告审核状态。
- 从咨询事项进入填写转介信携带明确 caseId。新信作为内部草稿，单次咨询保存后立即提交专员；MDT保存后返回确认完整专家名单再提交。
- 专员预约仍走原有时间占用及并发冲突防护。最终派发前重新检查来源报告审核状态。
- 已有旧信不自动关联；由顾问确认一次，避免把同客户不同事项的信误关联。未迁移、未代提交真实客户资料。
- 工作台增加专家咨询预约分类，并在提交流程后刷新资源。
- 不再把自动比对未知值显示成审核待办；>41.00 对照 0–1.75 能明确标红。多条件未知保留原文，不判正常。
- 新快照保留报告ID和审核状态，未审核项目在编辑区提供报告入口。历史无来源ID的快照由顾问确认资料，不自动猜测来源。
- 只读核查当前指定客户：事项intake、未关联转介/未确认专家，健管账号有效且与所属专员一致；不记录姓名或ID到此文档。
