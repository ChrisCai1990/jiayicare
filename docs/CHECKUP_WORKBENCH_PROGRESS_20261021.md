# 体检方案工作台进度修复（2026-10-21）

## 规则
- 工作台按年度体检方案全部项目计算完成度，不再只统计有 labTest / specialExam / functionalTest 类型的项目；未关联库、无类型、历史缺状态项目均保留待核对。
- 所有项目均为 completed 才进入已完成；部分完成显示核对中，全部未完成显示未完成。skipped 单独显示，不等同于实际完成。
- 方案总状态不覆盖逐项完成度；取消方案和无项目方案不进入此列表。只读汇总，不修改客户记录或原始方案状态。
- 原接口默认仍只返回未完成方案；includeCompleted=1 允许医护工作台查看已完成及全部。客户可见范围沿用现有岗位归属过滤。
- 每页5份，所有方案可翻页；客户数按客户去重，并另显示方案数。刷新失败保留上次数据，显示错误与重试。

## 验证
- 回归覆盖已关联项目完成后其余未关联项目仍保留、全部完成及撤销后恢复、跳过及缺状态、取消及范围过滤。
- 实际路由处理器测试覆盖员工客户范围及已完成查询。
- 真实组件 DOM 交互覆盖第6份方案翻页、状态筛选、详情跳转、完成后退出待办与历史查看、失败重试。
- 本地11项回归通过；医护端 Vite 生产构建通过（2048模块）。上线结果记录在本次发布回执。
- 线上客户数据只读核验未执行（自动审批拒绝），未访问或修改客户健康数据。
