# 家庭关系双端同步与授权

- 用户端由一人邀请、另一人接受后，`familyLinks` 双向建立。医护端从同一字段读取，自动显示已绑定关系。
- 医护端确认两位成年客户的关系时，分别为双方建立 `source=staff` 的待授权邀请，并在医护端显示该关系及授权状态。此时不写 `familyLinks`，家庭服务、代付等用户权限不会开放。
- 双方分别接受后，才幂等建立双向 `familyLinks`。一方拒绝时双方邀请终止；用户解除关联时双方用户权限撤销，医护端保留已核实但未获授权的关系状态。
- 授权绑定后的成年人可互看只读健康档案与报告、代传报告，并按现有规则代付；仅服务包明确标记 `familySharing` 的权益可共用。直接监护的孩子沿监护关系使用相同的档案与报告入口，可使用监护人名下明确可家庭共享的服务包权益。个人基金、积分和不可共享的权益不因家庭绑定转移。
- 用户端查看家庭成员和医护端查看关系不再根据既有关系网络自动扩展成员。成年人之间每一对用户关系都须经邀请接受或双方授权，不能由共同家庭成员推导权限。
- 既有 `familyLinks` 保留。儿童监护关系走独立的 `ChildGuardianLink` 流程，不使用此成人家庭授权机制。

本次只修改本地代码。小程序原有的“服务与代付”流程保留，本次增加家庭档案切换和报告上传入口；App 家庭成员页也提供档案、报告和上传入口，现有 App 尚无家庭代付页面。上线前需在隔离数据库验证双方接受、单方拒绝、撤销、医护端状态及家属报告权限，并构建医护端、App 与小程序；小程序仍需按平台流程发布。
