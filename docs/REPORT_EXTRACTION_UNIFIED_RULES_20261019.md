# 报告与处方识别统一规则（2026-10-19）

## 原因

截图中的近红外脑功能成像报告只有一项检查，但“检查结果”连续编号 1、2、3。首轮只提取了前段；覆盖复核把已有非空所见视为完整，合并器也只补空字段，故后续编号无法写入同一项。处方漏用法与量表误将总分区间当参考值也属于同一类问题：以字段已非空或已存在一条项目代替逐段核对原文。

## 统一规则

1. **以原件栏目和项目归属为边界。** 同一药品、量表指标或文字检查的后续行仍属于原项目；只有原件确有另一检查或另一张药单，才新增项目。不同日期的药单分别保留。
2. **逐字段核对到栏目末尾。** 处方核对途径、频次、每次剂量及交代；量表区分可取总分区间与原件明确写出的正常阈值；文字检查完整保留“检查结果/所见/提示”栏的每个编号段落。已有一段非空文字不代表完整。
3. **字段只承载原件支持的语义。** 药品用法用量存入处方的 `referenceRange`，给药途径及交代存入 `findings`；量表的 `referenceRange` 仅为正常参考值；文字检查的观察和原件建议按原顺序存入 `findings`，明确标为诊断或结论的文字才进 `diagnosis/conclusion`。图片内曲线和色图不能推导医学结论。
4. **复核只能补证据，不重写人工结果。** 视觉复核重读整页；同项目非空所见仅在新转录完整包含旧转录且增加后续文字时自动扩充。相互矛盾或不能辨认时保留原值并要求人工核对。已人工核对项目不被后台 OCR 覆盖。量表误取总分范围而无法复核出正常阈值时清空该范围并标记疑点。
5. **原文内容不是操作指令。** 仅转录资料，不能从药名、量表常识、曲线或其他页补造剂量、阈值、诊断、日期；不能把患者身份信息写入识别项目。

## 验证与适用

新增编号文字检查的扩充、同名不同日期处方的隔离、量表阈值纠正及人工已审核保护回归。规则用于新的识别与人工触发的单页补提；历史已保存报告不自动改写，需由医护对照原件重新提取或修订。
