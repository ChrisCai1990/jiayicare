# 血压与体重每周监测滚动规则（2026-10-30）

- 客户同意后的血压和体重常规监测由系统自动提醒，不自动派发健管专员工作台任务。专员为偏好人工服务等特殊客户另建“日常跟进”计划时，无论跟进内容是否为血压或体重，该任务仅在工作人员工作台，客户不看见此随访；自动提醒独立运行。历史年度方案生成的“标准随访 · 【日常跟进】”也按内部任务过滤。
- 对另建的每周监测随访，血压和体重分别保持一条当前待完成的任务。新建合并选择时拆成两条，逾期未完成的项目仍停留在原任务。内部任务由专员实际跟进后完成，并从完成日顺延七天。
- 健管专员执行内部每周血压或体重随访时，在任务内填写实际测量时间、数值和人工跟进结果。提交后生成一条关联该任务的健康档案监测记录，任务完成，并从实际测量日期顺延七天生成下一条内部任务；档案记录可在客户详情的“日常监测记录”查看。重复提交按任务固定记录 ID 去重。
- 对仍是客户可见的历史每周测量随访，客户在任务日期或之后自行记录相应项目，系统自动完成该项并生成下一次；已有合并任务在单项录入后保留未测项目。内部“日常跟进”不会因客户自行记录而自动代替专员完成。
- 基础监测提醒不再默认每周一。每项以最近一次有效记录日期为锚点顺延七天；首次无记录以完成建档日期为锚点。到期未测持续显示，记录后重新计算。内部跟进任务不改变客户是否接收自动提醒的设置。
- 有明确每日或每周两次规则的客户仍按既有高频规则执行，不按单周滚动。
- 发布状态以服务器实际提交与上线验证为准。旧任务不批量改写；在客户后续录入时逐项兼容。
