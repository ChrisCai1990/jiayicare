# 报告按内容类型解析与原文校验（2026-11-10）

## 本轮问题

- 年度体检 PDF 的同页多项检查可能把上一栏目的检查所见写进下一栏目。截图中“子宫、附件彩超”的所见混入胆囊/胆管文字，是字段归属错误，不能仅靠整页文字存在性校验。
- 单页补提会返回大量候选，但提示未区分已有重复、无可核对结果及其他待核对项目。
- 检验和检查原先共用通用报告提示；处方已有独立提示与结构化审核，门诊病历已有独立提取和结构化审核流程。年度体检仍可能在同一 PDF 中混有检验和检查栏目。

## 本地候选实现

1. `lab_report` 首轮及单页补提加检验行专项规则，`exam_report` 加检查栏目专项规则；年度混合报告继续使用通用首轮规则，处方、病历维持各自流程。
2. 独立原文转录按印刷栏目返回 `sections[{title,clinicalText}]`。年度报告及独立检查报告的检查候选必须与唯一栏目对应，所见和诊断逐句只在该栏目内核验；旧转录格式或栏目不明时拦截检查候选并标记待核对。历史已保存条目不自动改写。
3. 单页补提的检验/data 候选增加同一印刷行核对：名称、结果及有值的单位必须同处一行，数值不允许用另一数值的子串冒充。原文转录无表格行时留待人工核对。
4. 页级证据记录栏目不符、表格行不符、原文未核实和文字不可辨的拦截数量。补提接纳 0 项时，提示候选中已有/无新增字段、缺可核对结果、其他待核对数量。

## 验证与限制

- 纯函数及路由隔离回归 56 项通过；后端语法、JSX 语法与差异空白检查通过。既有 `reportExtractionQuality.test.js` 中“通用提示词少于 2000 字符”的断言在生产基线也失败，本轮没有改动该通用提示词。未调用真实患者报告或外部模型，未部署。
- 独立模型能否稳定按栏目返回结构，需用脱敏原 PDF 做对照试验。栏目识别不清会增加待人工核对项目，不能凭单元测试声称漏提率和串栏率已达标。
- 扫描件的完整 OCR 优先、PDF 文字层和版面坐标尚未完成；本轮先加入错误入稿拦截和单页补提的逐行核验。正式切换前应以跨医院样本评估漏项、错列、串栏、耗时和调用预算。

## 通用版式续修

不同医院和不同年份的 PDF 不应按固定模板作为主路径。独立转录现在以印刷栏目为边界，输出栏目标题、叙述原文及可选的结构化检验行 `rows[{name,value,unit,referenceRange}]`；单页补提按栏目和同一行核对候选，并统计原件中有名称和结果却没有进入审核草稿的行。数值 `0` 保留，重复扫描到的相同行去重。旧版纯文字行格式可继续核验，专用医院模板只保留既有兼容用途。

这是通用证据结构，不等于已完成任意 PDF 的自动准确解析：当前文字层优先、扫描件 OCR 引擎替换、版面坐标、处方跨行药嘱和病历栏目覆盖仍待实现与真实样本对照。没有原 PDF 时不能宣称未知医院版式已通过；新结构失败时应保持待核对状态，不猜测补写。
