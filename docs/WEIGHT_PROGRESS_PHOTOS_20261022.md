# 体重管理体型照片归档

## 入口

- 医护端：客户档案 → 服务方案 → 营养管理 → 体型照片。
- 客户 App／小程序：记录健康数据 → 体型照片。
- 可按管理前、阶段记录、管理后及正面、侧面、背面存档，记录实际拍摄日期。医护端可按营养方案周期筛选并选择两张照片并排查看；同日已有的体重、腰围、体成分值在对比区显示，不用照片推断疗效。
- 客户可选择已推送给本人的营养方案；没有方案时允许暂不关联。医护端“全部周期”仍可找到未关联的客户上传照片。

## 数据与权限

- 独立 `WeightProgressPhoto` 集合，仅保存元数据和私有 OSS 对象键，原图不写入 MongoDB 或公开 uploads 目录。读接口只返回短期签名链接。
- 客户仅可查看本人照片，并仅可移除本人上传的照片。医护端限同机构、直接负责该客户的健管专员／健康顾问／营养师及超级管理员；写入还需客户档案编辑权限。
- 上传前客户主动确认用途；医护代上传需勾选已说明用途并确认客户同意。保存同意时间、上传人及来源。删除为软删除，保留删除人和时间，列表立即隐藏，不删除历史原图。
- 上传限 JPG／PNG／WebP／HEIC／HEIF、12 MB；服务端核对内容头、拍摄日期、方案归属。照片仅用于人工对比，不进入聊天、AI、家庭共享或常规打卡数据。

## 发布与验收

- 需要后端与三端配套发布；小程序构建成功不代表已上传、提审或正式发布。没有生产数据迁移和历史照片回填。
- 上线前用虚构客户验证本人上传、医护代传、不同机构及非负责医护拒绝、客户不能删除医护照片、方案周期筛选、删除留痕、私有链接过期后刷新，以及手机实拍 HEIC/JPG 的方向和显示。
