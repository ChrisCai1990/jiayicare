# 健康顾问统筹与群对话布局

- 用户明确：所属健康顾问统筹查看客户所有服务群；其他岗位只查看本人参与的群，团队负责人可只读监管本团队实际入群成员参与的群。
- 收紧原 isAssignedLeader 跨群通道为同机构、有效的所属健康顾问；列表、消息读取及待办计数共用此判断。保留基于 Team.mentorId / Admin.teamId 的监管，以及群成员身份发送校验。所属营养师、专科医师、就医专员、健管专员不再仅因客户分配关系获得跨群只读权限。健管仍可配置群。
- 页面不再把所有筛选与聊天压入一屏固定高度；聊天工作区保留最低560px，窄屏680px，外页可滚动。聊天内消息独立滚动，输入区不覆盖消息。去除客户身份区冗余换行。
- 12项规则测试通过；隔离Mongo对四类群的五岗位列表/读取验证、营养团队负责人不入群查看及禁止发送验证通过。合成浏览器在1440×900、1280×720、1024×600、800×600检查消息区高度、发送可达性和不重叠；未发送真实客户消息。
