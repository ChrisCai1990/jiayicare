# 市场合伙人档案与团队名册

2026-11-13：管理端将合伙人档案、业务登记和财务审核拆为独立入口。

- 「市场合伙人」维护合伙人板块、合同编号、推荐码、状态和团队成员名册。成员按所属合伙人登记姓名、手机号，可暂停或修改；修改留原因与前后版本。
- 「合伙人业务登记」处理首次沟通证据、线下合同订单、正式流失和年度已付年序，并提供逐单核算与业务归属查看。
- 「合伙人财务审核」处理线下收退款凭据和合伙人佣金转账核对。人员推广与服务佣金仍在统一「佣金规则」设置。
- 旧逐商品合伙人规则与团队专项激励在嘉医汇正式环境均为零条，管理端入口撤下，后端历史兼容保留。

团队成员名册当前不产生个人推荐码、客户归因或佣金。团队市场拓展比例尚未确定，后续规则须明确成员推荐证据、合伙人与成员之间的分配基数、冲突优先级和退款冲回；在规则上线前，合伙人原推荐码仍只归属合伙人本人，不能把名册当作已实现团队分账。
