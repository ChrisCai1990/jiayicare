# 年度方案按方案分流（2026-11-19）

## 决策

按方案首次保存时的版本分流。同一成员可以保留旧版方案和随访，并在以后创建新版方案。金娟已有旧版方案，继续保持原有兼容入口。已有旧版方案的成员不按人拦截，也不批量迁移历史数据。

## 实现边界

- `AnnualPlan.flowVersion` 在首次保存时固定为 `1` 或 `2`。历史记录未标记版本：金娟沿用原试点能力，其他成员按旧版处理。再次保存或局部修订不得改变版本。
- `ANNUAL_FLOW_NEW_PLAN_MODE=all` 只决定启用后首次保存的新方案。未启用时，其他成员的新方案仍为旧版。现有 `ANNUAL_FLOW_MODE=all` 不再用于扩大年度流程。
- 年度页、专项筛查、目标、营养、康复、执行任务都根据关联方案的版本决定入口和操作。没有方案时，页面可预览新建候选流程。已生成随访保留原有规则；从新版方案新生成的任务写入 `formData.annualFlowVersion=2`，后续操作按该标记运行。
- 阶段复盘名单 `MANAGEMENT_REVIEW_MODE=phase_assessment` 保持原样。

## 启用与核验

发布代码并完成针对性测试后，设置 `ANNUAL_FLOW_NEW_PLAN_MODE=all` 并重启后端。从配置实际生效之后首次保存的方案开始采用新版；生效之前已保存的方案继续沿用旧版。抽查金娟旧方案、其他成员旧方案、新保存方案及其随访，并核对方案版本不会在再次保存时变化。

如需停止新方案进入新版，撤销 `ANNUAL_FLOW_NEW_PLAN_MODE` 并重启。已有新版方案继续按其固定版本办理。
