# 首页信息层级优化

健康概览与记录入口合并，评分降为辅助；问候不再直接宣称健康状态。小程序顶部避让微信胶囊、不显示调试版本。连续记录改为近30日辅助文案。近期安排标题隐藏括号内长说明，详情和真实操作保持原样，不删除任务或改状态。

首页只增加会员权益/健康基金两张快捷卡；基金带 section=fund 参数直达原权益页的基金区域。底部导航和个人中心原入口保留。商城展示靠后，原价格、支付和基金扣减不变。

与预览的差异：本轮保留真实安排原顺序与提醒展示，未依据推测自动重分任务归属；没有新增任务分组状态。评分算法、客户数据、企业配置均未修改。

发布需先运行 homePresentation、现有小程序回归及实际产物兼容测试，标准发布跳过数据迁移；正式小程序发布由用户确认。
