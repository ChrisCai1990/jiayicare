# 商城已购人数展示

后台「收费产品管理」新增「已购人数」列，可查看线上已付款人数、历史线下成交人数和对外显示的合计。机构超管及经理可设置已核实的历史线下成交人数，并填写记录来源。商品价格、库存和履约规则不受此字段影响。

对外显示人数 = 已核实的历史线下成交人数 + 线上已付款客户去重人数。线上数据从有效已付款订单实时统计；同一客户重复购买只计一人，退款后不再计入。合计为 0 时，网页商城不显示购买人数。已发布小程序仍按其现有页面规则展示接口返回的人数，页面文案或隐藏 0 的调整需要另行发布小程序版本。

后台修改历史人数采用商品更新时间校验，防止并发编辑覆盖；不允许填写负数、小数或超过 100 万，不允许有历史数却没有记录来源。历史值仅用于已核实的线下成交，不应用作虚构购买记录。
