# 商城已购笔数展示

后台「收费产品管理」新增「已购笔数」列，可查看线上有效已付款订单数、历史线下成交笔数和对外显示的合计。机构超管及经理可设置已核实的历史线下成交笔数，并填写记录来源。商品价格、库存和履约规则不受此字段影响。

对外显示笔数 = 已核实的历史线下成交笔数 + 线上有效已付款订单数。线上数据从订单实时统计；同一客户每次购买分别计入，全额退款后不再计入。套餐的一笔订单仍计一笔，套餐内可核销次数不作为购买数量。合计为 0 时新商城不显示笔数。旧版 H5 和小程序仍读取原“人已购”兼容字段，该字段继续按客户去重，避免旧文案误称笔数为人数；小程序文案调整需要另行发布客户端版本。

后台修改历史笔数采用商品更新时间校验，防止并发编辑覆盖；不允许填写负数、小数或超过 100 万，不允许有历史数却没有记录来源。历史值仅用于已核实的线下成交，不应用作虚构购买记录。旧版历史成交人数与新笔数口径不同，不自动迁移；上线前须核对是否曾填写旧值。
