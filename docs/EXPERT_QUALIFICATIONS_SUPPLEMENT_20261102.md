# 专家资质与语言补充

本轮本地实现，尚未发布。此前学历补填版本为 242e0ef8；线上状态以实际发布核验为准。

- 合作问卷增加服务语言及每种语言能力：可专业咨询、专业咨询需翻译、仅阅读资料。不默认假定语言能力。
- 首次问卷提交后转入个人补充页，上传医师资格证、执业证、职称证、学历／毕业证、学位证、其他专业资质。个人链接可反复使用30天，库中仅保存哈希；后台生成新链接后旧链接失效。共用招募链接不返回个人问卷或证件。
- 后台问卷详情可展开资质与语言，补填学历／语言、代上传附件、下载及逐份标注核验结果。已入库专家可补充，附件默认待核验，不自动改变原准入结论或服务资格。
- 附件最多20份，每份10MB，允许JPEG/PNG/WebP/PDF，检查文件头。OSS独立目录且显式private ACL，仅经鉴权/个人能力链接和归属校验后受控下载，不返回对象key/公开URL。不读取或修改生产证件。
- 个人补充页只开放学历、语言、附件，不能修改报价、身份、审核结果；拒绝/撤销问卷不能使用补充入口。其他岗位语言字段与派单语言筛选本轮未接入。
- 验证：隔离Mongo实际multipart接口、同一共用链接下不同专家附件隔离、跨机构拒绝、普通角色拒绝、失效/轮换链接、超限与伪造文件、审核状态；私有ACL单元测试；Admin构建。
