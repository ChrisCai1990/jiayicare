# 高端险事后报销原始资料

在医护端客户详情的“原始资料”上传时，勾选“归入高端险事后报销资料”。该用途标记用于在原始资料页集中筛选，不改变资料本身的医疗分类。

- 门诊病历、检验报告、检查报告继续使用原有分类和解析、核对流程。
- 发票、费用清单及其他报销票据选择“报销票据／费用清单”。该类型自动标记为高端险事后报销资料，仅保存原件，不做自动元数据识别、医疗解析、审核待办或筛查汇总。上传需客户所属健管专员或超管，且必须有原件文件。
- 同次体检完整报告的原有“仅存档”规则保持关联已审核结果报告；报销票据独立存档，不要求关联报告。

本次仅处理资料分类与存档，不建立理赔申请、金额或保险公司流转状态。既有资料不自动改类；上线前须按发布流程构建并核验前后端。
