# 体检顾问一次确认：单项验收

2026-09-22；仅功能分支、隔离本地，未推送或部署生产。

## 操作

1. 健管完成本次报告回收与审核。
2. 健康顾问工作台打开“体检结果评估与随访计划”，核对本次报告；选择后续计划或明确无需后续，填写结论、确认资料齐全，点击“一次确认体检评估与后续安排”。
3. 有后续时复用既有草稿审核/发布，成功后保存本次服务结果。没有后续则保存明确决定，不虚构任务。
4. 按原流程完成最终验收及必要核销。原健管随访此前保持未完成，条件齐备且审核依据未变才自动结案；不再要求顾问第二次确认。
