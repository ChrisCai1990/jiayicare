# 嘉医汇健康管家｜安卓应用市场提交包

版本：1.0.0（versionCode 1）  
提交主体：杭州嘉医汇健康管理有限公司

## 通用展示文案

**一句话简介**：嘉医汇健康管家，为健康记录、健康规划与服务沟通提供便捷入口。

**应用简介**：嘉医汇健康管家支持健康数据记录、健康档案查看、体检资料上传、健康规划与服务沟通。应用提供健康教育和健康管理相关信息，不替代医生诊疗、诊断、处方或紧急医疗服务；紧急或严重不适请及时前往医疗机构就诊。

**关键词**：健康管理、健康记录、健康档案、健康规划、随访提醒、体检资料整理。

## 审核说明

1. 未登录访客仅查看公开介绍；健康档案、体检资料、订单与服务沟通需要登录。
2. 相机与相册仅在用户主动上传资料时请求；拒绝授权不影响其他功能。
3. 不提供在线诊断、处方、急救或疗效承诺。
4. 若需要审核账号，由运营方单独创建可回收的测试账号；不得提交真实客户资料或员工账号。

## 账号开通后执行顺序

1. 以杭州嘉医汇健康管理有限公司营业执照注册应用市场企业账号。
2. 生成 Android AAB 正式包，签名后上传首个市场。
3. 上传商店图标、截图、上述文案、隐私政策链接与权限说明。
4. 用空白测试账号走完登录、资料上传、服务下单、隐私页和注销入口。
5. 提交审核并记录各市场的审核状态与补充材料要求。
