# 专家招募已签协议归档与心理咨询师 Word 草稿

## 2026-11-14 专家本人查看

- 专家提交问卷后进入专属“资料补充”链接；页面显示待审核或已审核入库。已入库且管理员已归档手签协议时，同一页面列出并可下载已签文件；尚未归档时显示等待提示，可手动刷新。
- 多人共用的问卷邀请链接不读取任何个人协议。个人链接限本人持有，30 天到期；管理员可为该记录生成新的个人链接并转交本人。文件下载继续按个人链接哈希、有效期与当前记录校验，且仅在已入库后开放；列表不返回 OSS 路径、哈希和其他内部字段。
- 管理员归档权限和 Word 草稿生成规则不变。合作方只可下载已归档手签文件，不能在个人页面上传或更换合同。

## 本地实施

- 基于 2026-11-13 可读取的 `origin/master` 建立独立工作树 `expert-signed-contract-archive-20261113`，分支 `feat/expert-signed-contract-archive-20261113`。发布前远端更新后，已快进到 `cc8ce2db`；其余变更不与本功能重叠。
- 管理端“专家招募与问卷”的已审核入库记录新增合作协议区。心理咨询师可下载由已核准姓名、单次费用生成的 Word 草稿；管理员可归档双方手签的完整 PDF 或图片，记录签署日期、协议编号、上传人、时间及 SHA-256。追加新版本，不覆盖历史。
- 私有文件放在 `expert-signed-agreements/<tenant>/<recruitment>/`。2026-11-13 初版仅机构管理员与经理在受限后台下载；11-14 增加已审核专家通过有效个人补充链接查看本人已归档文件。归档文件不自动宣称电子签名或自动验证手签真实性。
- Word 正文含嘉医汇签约主体、50分钟标准服务、上月21日至本月20日结算和本月25日付款、遇节假日顺延至其后首个工作日、未完成服务不计费及30日终止通知。签署前须人工补齐身份证号、合作截止日期和签署日期，并由法务审定文本。

## 验证

- `backend/test/expertSignedAgreementArchive.test.js`：4项通过，覆盖有效归档、未审核/未确认/未来日期拒绝、重复文件清理、管理员角色拒绝、补充链接无访问路由及 Word 文件结构。
- Admin Vite 生产构建通过（使用同工作区现有依赖的临时 junction，构建后已移除）。
- 生成的 DOCX 通过 `python-docx` 读取，24个段落。`render_docx.py` 因本机缺少 LibreOffice 无法直接生成页面 PNG；改用本机 Word 导出 PDF，再将两页逐页渲染为 PNG 检查。初版为三页且末页留白过多，已调整行距；复核版为两页，正文、空白字段及签章区完整、无裁切。
- 功能已固定为本地 Git 提交。GitHub 连接器返回账号暂停；命令行 Git 可公开读取，但推送试运行缺少可用凭据，本机亦无可用 SSH 身份。按照本项目先推送同一提交、再部署阿里云的发布链，本轮尚不能宣称上线。
