# 嘉医汇知识中心内容工作流

这里是知识中心的内容源，而不是直接编辑网页的位置。每篇文章一个 JSON 文件，统一经过生成器产出页面、页面元信息、首页最新阅读目录和站点地图。

## 发布状态

- `draft`：编辑中的草稿，只能用于内部预览。
- `review`：待审核稿，只能用于内部预览；健康教育内容应由业务与专业人员核对表述、出处及风险提示。
- `published`：已完成审核、可以公开发布的稿件。只有这种状态会在正式构建时进入公开页面和站点地图。

请不要把“审核中”改成 `published` 来绕过审核；网站不应把个体诊断、处方建议、疗效承诺或未经核验的医学结论作为公开内容。

## 每篇文章的必填字段

- `slug`：英文短路径，例如 `healthy-weight-start`。
- `title`、`summary`、`updatedAt`：面向读者的标题、摘要与更新时间。
- `status`：上述三种状态之一。
- `reviewedBy`、`reviewedAt`：只有 `published` 时必填，记录审核责任与日期。
- `sections`：正文段落；正文使用健康教育语言，避免替代医生诊断。
- `sources`：可核验的权威出处链接。

## 日常操作

1. 新建或更新 `content/articles/*.json`。
2. 运行预览构建，检查稿件页面：`node scripts/build-content.mjs --preview`。
3. 专业与业务审核完成后，补全审核字段并将状态改为 `published`。
4. 运行正式构建：`node scripts/build-content.mjs --publish`；它只会写入已发布内容与站点地图。

`--publish` 不负责把网站部署到互联网；公开部署仍需在构建与验收通过后单独进行。
