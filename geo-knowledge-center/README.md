# 嘉医汇健康知识中心

公开、静态、移动端优先的健康教育内容站首版。上线前需将 `SITE_URL`、主体信息、专业审核人、测评/预约承接链接替换为已确认的正式信息，并完成内容审核。

## 本地预览

可由任何静态文件服务器托管该目录；不依赖现有 App、小程序或后端。

## 首版页面

- 首页与体重代谢专题入口
- 已审核的高意图健康教育内容页
- `ai-consultation.html`：只处理非医疗咨询准备；访客明示同意后可提交最少联系信息，由医护端“会员营销 → 官网线索”承接
- `robots.txt` 与 `sitemap.xml`

## 发布前必做

1. 替换 `https://jiaycare.com` 为确认后的公开站点地址（如有变化）。
2. 补入可公开的主体、联系方式、服务边界、隐私与测评授权链接。
3. 每篇内容补齐作者、审核人和更新日期，并完成专业审核。
4. 为 `/api/visitor-assistant` 配置与官网同域的后端反向代理，并复核 AI 服务密钥、限流、HTTPS 与医护端线索交接权限。
5. AI 咨询入口不得收集病历、症状、检查指标、报告或用药信息；正式发布前须完成隐私政策变更审核。

发布前运行 `node scripts/release-preflight.mjs`。如发现未审核文章、未确认的隐私政策页或域名配置问题，检查会阻止部署。
